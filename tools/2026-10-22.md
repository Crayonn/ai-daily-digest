# AI 工具日报 2026-10-22

## 一、AI 工具类

**1. Claude Code 连发两版（10-21）：v2.1.306 / v2.1.307**

为什么值得知道：MCP 重度用户（接了一堆 server 的人）升级最划算——去重直接省 token。

来源：[TurboAI](https://www.turboai.dev/)

**2. Gemini CLI v0.65.0（10-20）：恢复会话保留历史**

resumed sessions keep history，不再 auth 死循环，支持自定义 OTLP headers。

为什么值得知道：被 auth 循环折磨过的可以直接升。

来源：[TurboAI](https://www.turboai.dev/)

**3. OpenCode 2 v2.1.2（10-21）**

发布分析只记录了版本号，具体 changelog 见 GitHub release（未逐条核对，不展开）。

来源：[TurboAI](https://www.turboai.dev/)

**4. Glean 推出 headless agent building（10-21，GA）**

从 Claude Code / Cursor / Codex 里用代码写 agent，跑在 Glean 托管运行时上，接 275+ 企业数据源，权限/审计沿用 Glean 的企业治理；不想写代码的继续用可视化 agent builder。

为什么值得知道："agent 即代码"第一次有了企业级托管答案——版本控制、测试、回滚全套软件工程流程直接套用。

来源：[Unite.AI](https://www.unite.ai/glean-adds-headless-agent-building-for-claude-code-cursor-and-codex/)

**5. Hedera Network MCP 上线 testnet（10-21）**

给 Claude Code / Codex / Cursor 40+ 链上工具：agent 可以起草转账、mint token、查网络，但最终签名权在用户自己的钱包——"agent 提议、你拍板"，不碰私钥。

为什么值得知道：agent 碰钱的最大障碍是"不能给私钥"——"起草+钱包终审"这个模式是标准答案的样子。

来源：[Genfinity](https://genfinity.io/2026/10/21/hedera-network-mcp-testnet-ai-agents-wallet-signing/)
