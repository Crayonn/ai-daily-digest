# AI 工具日报 2026-11-10

## AI 工具类

**1. Claude Code v2.1.321（11 月 9 日）：Fable 5.2 成默认模型，修了一个 MCP OAuth 漏密钥 bug**

118 条改动：Fable 5.2（claude-fable-5-2）成为默认 Fable 模型，100 万上下文、8/40 美元每百万 token、缓存读取 0.20 美元；`claude remote-control` 支持 `--settings <file>`，给所有会话统一套设置；VSCode 侧在 token 与 API key 同时设置时弹警告。安全修复：MCP OAuth 请求在服务器重定向时曾把 refresh token 等密钥发给另一台主机，已修；另修一批 Bash 权限问题。已保存的 Fable 5.1 选择自动迁移到新版，可用 `/model claude-fable-5-1` 切回。

为什么值得知道：一次升级同时拿到新旗舰模型与一个真实的密钥泄露修复——后者才是该立刻升的理由；remote-control 的 --settings 则让多会话管理第一次有了统一入口。

来源：[Claude Code v2.1.321 发布说明（11 月 9 日）](https://www.claudeupdates.dev/version/2.1.321)、[TurboAI 发布分析（11 月 9 日）](https://www.turboai.dev/)

**2. Muse Ember 进 Muse Code（11 月 9 日）：Meta 最小模型当 agent 的"量产工"**

muse-ember-1.0 同步上架 Muse Code 与 Meta Model API，定价 0.10 美元/百万输入、0.50 美元/百万输出 token，缓存输入仅 0.004 美元；100 万上下文、最高 51.2 万输出，原生读文本、图像、音频、视频。Meta 的分工表述是"Muse Wonder 规划、Muse Ember 扛量"，早期测试方包括 Box、Cline、Oracle、Cloudflare、You.com。

为什么值得知道：coding agent 的子任务（读文件、跑测试、小修小补）第一次有了"每任务 0.14 美元"量级的官方选项；主模型规划、Ember 批量执行的分层跑法，值得在下一个 agent 流程里试着拆一层。

来源：[Meta Research（11 月 9 日）](https://research.meta.ai/blog/muse-ember)

**3. Claude Personal Finance beta（11 月 6 日）：Claude 能连银行、信用卡与投资账户了**

Claude 发布说明新增"Personal Finance in Claude"：beta 功能，可链接银行、信用卡、贷款与投资账户，在一页里看余额与支出，并直接问 Claude 关于自己钱的问题。仅限 Pro、Max、Ultra 订阅，美国 only；同期企业版新增安全中心、推理钩子（inference hooks）、集中管理与项目标签 beta。

为什么值得知道：Claude 从"通用助手"伸进个人财务数据——这是订阅档位的又一次分层（免费版没有），也是 agent 读敏感数据的信任测试；美国以外的用户目前只能看。

来源：[Claude 帮助中心发布说明（11 月 6 日更新）](https://docswatch.stevetoth.ai/anthropic/claude-help-center-release-notes/2026-11-06/)

**4. Codex CLI v0.167.0（11 月 6 日）：agent 指挥中心 + Vertex AI 入门 + 后端切换**

OpenAI 的 Codex CLI 更新：新增 agent command center（集中看管多个 agent 会话）、Vertex AI 上手流程、后端切换能力。同期 ChatGPT 桌面版的 Codex 已被曝出沿用用户 SSH 配置转发 agent socket 的问题（见早报第 6 条），用远程 Codex 前先查 ForwardAgent 设置。

为什么值得知道：Codex 正在补"多 agent 并行"的管理层——指挥中心对标的是 Claude Code 的并行会话；但远程能力越强，SSH 这类本地凭证边界越值得先收紧再扩。

来源：[TurboAI 发布分析（11 月 9 日）](https://www.turboai.dev/)、[AgentVera 变更日志（11 月 9 日）](https://agentvera.dev/en/agent-changelog/)

**5. OpenCode 2 v2.2.6（11 月 6 日）与 Gemini CLI v0.67.0（11 月 4 日）：开源 agent 双线小步快跑**

OpenCode 2 升至 v2.2.6、Gemini CLI 升至 v0.67.0，均为常规迭代；Amp 同期升至 v0.0.1794139239（11 月 8 日）。本周六款主流 coding agent 全部有新版，最新版一览：Claude Code v2.1.321、Codex CLI v0.167.0、OpenCode 2 v2.2.6、Gemini CLI v0.67.0、Amp v0.0.1794139239。

为什么值得知道：coding agent 已进入"周更"节奏，版本号本身成了风向标——Claude Code 几乎每天一版、其余几家周更；选工具时除了模型，更要看谁的发布节奏跟得上。

来源：[TurboAI 发布分析（11 月 9 日）](https://www.turboai.dev/)、[AgentVera 变更日志（11 月 9 日）](https://agentvera.dev/en/agent-changelog/)

## AI 视频类

**1. Gemini Omni 1.2 Flash（11 月 5 日）：15 秒音画同步视频 + 多轮对话式编辑，720p 约 0.07 美元/秒**

Google 的 Gemini Omni 1.2 Flash 把原生视频生成延长到 15 秒，音频与画面同步生成，支持多轮对话式编辑与更长的视频输入处理；API 定价 720p 约 0.07 美元/秒。Veo 3.1 已于 10 月 22 日从 Gemini API 下线，Google 明确推荐改用 Omni Flash。

为什么值得知道：带音频的视频模型里，Omni 1.2 Flash 仍是每秒最便宜的一档（Veo 3.1 标准版 0.40 美元/秒的约六分之一）；要批量出 15 秒以内的短片，它是目前的第一性价比选择。

来源：[Forasoft 文生视频 API 对比（11 月 8 日复核价）](https://www.forasoft.com/blog/article/text-to-video-api-comparison)、[Convly（11 月 8 日更新）](https://convly.ai/best-ai-video-generators-2026/)

**2. Kling 4.0 在 Runway 八折到 11 月 30 日：720p 每秒 0.157 美元 → 约 0.126 美元**

Runway API 上的 Kling 4.0（720p 0.157 美元/秒、1080p 0.235 美元/秒）八折持续到 11 月 30 日；Kling 4.0 自 10 月 15 日全量开放，单条最长 30 秒、带立体声，支持最多 10 个关键帧。

为什么值得知道：要长镜头（20–30 秒）又不想付 Veo 价，11 月底前是 Kling 4.0 最便宜的窗口；但注意这是 Runway 渠道价，Kling 官方至今未公布自己的开发者 API 定价。

来源：[Forasoft 文生视频 API 对比（11 月 8 日复核价）](https://www.forasoft.com/blog/article/text-to-video-api-comparison)

**3. Veo 3.1 停用倒计时 7 天：11 月 17 日起 Google Cloud 模型页提示停用**

Veo 3.1 已于 10 月 22 日从 Gemini API 下线，Google 推荐改用 Gemini Omni Flash；Veo 3.1 Fast 与 Lite 仍在 Google Cloud 上可用，但 11 月 17 日起模型页将提示停用。

为什么值得知道：还在用 Veo 3.1 出片的人只剩 7 天窗口——11 月 17 日之后要么切 Omni Flash、要么接受 Cloud 端的变化；依赖 Veo 3.1 做固定流程的团队现在就该测好替代模型的出片效果，别等停用当天再换。

来源：[Slash Digital 视频模型横评（11 月更新）](https://slash-digital.io/en/insights/video-models-2026/)、[Convly（11 月 8 日更新）](https://convly.ai/best-ai-video-generators-2026/)

**4. Runway API 变成"一家 API、十几个模型"：Veo、Kling、Seedance、Wan、Gemini Omni 同一 key 调用**

Runway 的 API  changelog 显示，8 月至 11 月间陆续接入 Hailuo 3.0、Seedance 2.5、Wan 3.0、Kling 3.0/4.0、xAI Grok 视频模型与 Gemini Omni 1.2 Flash，并上线 Model Router，按所选模型计费；自家 Gen-4.5 为 0.12 美元/秒、Gen-4 Turbo 0.05 美元/秒，Aleph 2 视频编辑模型 0.28 美元/秒起。

为什么值得知道：视频 API 的竞争从"谁家模型强"变成了"谁家聚合全"——一个 key 就能横评六七个模型，出片前先在同一个计费口径下比一轮，比逐家开户省事得多。

来源：[Forasoft 文生视频 API 对比（11 月 8 日复核价）](https://www.forasoft.com/blog/article/text-to-video-api-comparison)

**5. MiniMax H3 走 fal 渠道 480p 约 0.05 美元/秒：开源权重路线的最低价**

MiniMax H3 权重已上 Hugging Face，通过 fal 调用 480p 约 0.05 美元/秒；Wan 2.5 同价位也有 0.05 美元/秒的档。两者都是 11 月横评里"按秒计费最便宜"的选择，但分辨率与音画同步能力弱于 Omni 1.2 Flash 与 Veo 3.1。

为什么值得知道：批量出片、分辨率要求不高时，H3 与 Wan 2.5 的每秒价只有 Omni 的七成、Veo 的八分之一；先按"每秒价 × 成片秒数"算总账，再按榜单选模型，顺序别反了。

来源：[Convly（11 月 8 日更新）](https://convly.ai/best-ai-video-generators-2026/)
