# AI 工具日报 2026-11-23

## AI 工具类

**1. Claude Computer Use beta 进 Team/Enterprise 套餐，Claude Code 2.1.329 同步发（11 月 20 日）**

Anthropic 11 月 20 日发布说明：Computer Use beta 进入 Team 与 Enterprise 组织（逐步推送），新版 Claude Desktop 里 Claude 能看屏、操作用户授权的桌面应用；同批 Claude Code 2.1.329 加任务可见性、扩展 MCP 服务器支持、Code Mode 覆盖更广。同一周移动端也在改版（底部栏分出 Chat、Projects、Code、Artifacts，见昨日工具日报）。

为什么值得知道：Computer Use 从"个人尝鲜"变成"团队可用"，桌面 agent 正式进入企业采购清单；Code Mode + 任务可见性则是 Claude Code 往"多 agent 编排"走的又一步。

来源：[AI Briefing（11 月 22 日）](https://aibriefing.dev/)

**2. Grok 4.6 上 xAI API：50 万上下文；Grok Bot 1.0 接入 Slack/Teams（11 月 22 日）**

Grok 4.6 已上 xAI API，50 万 token 上下文、多档推理强度。Grok Bot 1.0 加团队协作：Slack 与 Microsoft Teams 内可用，还能订机票、酒店与租车。

为什么值得知道：50 万上下文 + 办公软件内嵌，Grok 正在从"聊天机器人"往"团队里能订票的 agent"走；xAI API 用户现在就能直接调。

来源：[AI Briefing（11 月 22 日）](https://aibriefing.dev/)

**3. Gemini 4 Hydrogen 进 Gemini App 与搜索；Gemini 3.5 Transcribe 公开预览（11 月 22 日）**

Google 的极速模型 Gemini 4 Hydrogen 已进入 Gemini App 与搜索；Gemini API 的 Gemini 3.5 Transcribe 开放公开预览，支持语音编辑式转录（比如"删掉最后一句"）。另见 AI 视频类第 1 条：聊天生成视频/3D 的 raea 当日登上 GitHub 日榜。

为什么值得知道：Hydrogen 是 Gemini 4 里最便宜、免费档可用的一个，进搜索意味着日常搜索背后的模型正在换代；Transcribe 的"语音改稿"对做播客与会议记录的人是直接可用的新能力。

来源：[AI Morning Brief（11 月 22 日）](https://www.aimorningbrief.dev/today)

**4. AWS 给 agent 发"最小权限"凭证：STS GetScopedCredentials（11 月 22 日）**

AWS 新 STS API GetScopedCredentials：可以把已有临时凭证的权限再收窄，每个 agent 与子 agent 只拿完成当前任务所需的权限，而不是继承父会话的全部权限。

为什么值得知道：agent 越权是本周泄露事件的另一面（见早报第 4 条）——Together AI 是 agent 提交了凭证，AWS 这边是给凭证"瘦身"；跑多 agent 编排的人，现在就能用这个 API 把子 agent 的权限关进笼子里。

来源：[AI Briefing（11 月 22 日）](https://aibriefing.dev/)

**5. 苹果 Depth Pro 2 上架 Hugging Face：单张图估深度（11 月 22 日）**

苹果把 Depth Pro 2 放上 Hugging Face：单张图像估计深度信息的模型。

为什么值得知道：苹果的视觉模型公开上架不多，Depth Pro 2 对做 AR、3D 重建与图像编辑的人是现成的免费基础能力。

来源：[AI Morning Brief（11 月 22 日）](https://www.aimorningbrief.dev/today)
