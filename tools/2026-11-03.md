# AI 工具日报 2026-11-03

## AI 工具类

**1. Claude 文本水印今天扩围：Mythos 5、Opus 4.7/4.6、Sonnet 4.6 从 11 月 3 日起带不可见水印，且无法关闭**

据 Anthropic 发给 API 客户的邮件（多家 11 月 2 日梳理）：从今天起，Claude Mythos 5、Opus 4.7、Opus 4.6、Sonnet 4.6 的输出将带上不可见的词选择水印；8 月 2 日后发布的新模型（如 Opus 5.5）自发布起已有水印。水印在模型层生效——Claude Code、API、App 与云厂商渠道的输出都带，不改语义、不加字符、随复制传播；检测目前只对监管、媒体、研究机构等开放私测，普通用户自己查不了。

为什么值得知道：对写代码的人，配置不用改（Claude Code、Codex、Cursor 设置照旧）；但“这段代码/文本是不是 AI 生成的”从今天起有了机器可验的答案——对外交付 AI 生成内容时，先想清楚水印这层再承诺“纯人工”。

来源：[AICodeWith 梳理（11 月 2 日）](https://aicodewith.ai/en/blog/claude-text-watermark-november-3-claude-code-api)、[AI Briefing（11 月 2 日）](https://aibriefing.dev/)

**2. DeepSeek 开源 Super-Agent 原型：一个常驻 Router + 多个并行 Worker，MIT 协议、但官方明说不是产品**

DeepSeek Harness 团队 10 月 31 日开源 deepseek-ai/dsh-superagent-prototype（MIT）：监听一个 GitHub 仓库（可选飞书），获授权的人提需求后，Router 会话接活、派给独立 Worker 会话并行执行、最后以 PR 回复。仓库 11 月 2 日时约 1.14 万 star；但 README 与设计文章都强调：只是研究原型、非官方产品、与内部版本不一致、部分设计是未来方向；Worker 默认以操作系统的用户身份无审批跑命令，屏蔽命令只是默认值、不是安全边界。

为什么值得知道：这是“agent 从单次会话变常驻同事”最具体的开源参考——架构值得读，但别直接部署到生产仓库：单独的 agent GitHub 账号、隔离环境、审批边界，缺一个都别上。

来源：[DevelopersDigest 梳理（11 月 1 日更新）](https://www.developersdigest.tech/blog/deepseek-dsh-superagent-router-worker-always-on-agent-2026)、[Michael Leung 拆解（11 月 2 日）](https://www.michaelleung.info/latest-news/deepseek-super-agent-explained)

**3. ChatGPT 与 Codex 12 月并额度（工具侧提醒）：桌面 App 合并 Chat/Work 标签页，Codex 仍独立**

OpenAI 11 月 2 日用户邮件（TechCrunch 报道）：桌面 App 的 Chat 与 Work 合并为一个体验，先小批试用；Plus、Pro、Business 档从 12 月起 ChatGPT 与 Codex 共用同一 token 额度，Instant 对话不计入。结合 10 月 29 日 Pro 档额度翻倍，12 月的实际可用量 = 翻倍后的额度 − 聊天与 coding 合并消耗。

为什么值得知道：对同时用 ChatGPT 查资料、用 Codex 写代码的人，12 月起要按“一个池子”做预算；现在就可以在设置里看各自用量，预估合并后会不会提前触顶。

来源：[TechCrunch（11 月 2 日）](https://techcrunch.com/2026/11/02/openai-is-finally-merging-chatgpts-chat-and-work-tabs/)

**4. Cursor 扩展投毒事件收尾提醒：恶意版 2.1.312/2.1.313 卸载后仍残留，须查 `svc-telemetry` 密钥**

10 月 29 日 Cursor 扩展市场 served 的 Claude Code 扩展恶意版（2.1.312、2.1.313，Windows/macOS，窗口约 11 小时、至多 5000 用户受影响）试图植入标为 `svc-telemetry` 的 SSH 公钥并建持久化；Cursor 与微软均说明：卸载扩展或升级到干净版 2.1.314 都清不掉扩展目录外的残留文件与启动项，须按 Cursor 安全公告单独清理，检查命令为 `grep -qs svc-telemetry ~/.ssh/authorized_keys`。

为什么值得知道：这是本周对开发者最实际的安全动作——10 月 29 日当天在 Cursor 里更新过 Claude Code 扩展的人，今天花一分钟查一次密钥文件，比任何事后扫描都值；官方渠道（VS Code 市场、OpenVSX）的同版本号未受影响。

**1. Marvell 1150 亿美元全股票收购 Lumentum：AI 集群的“电转光”赌局，2028 年上半年才交割**

Marvell 与 Lumentum 11 月 2 日宣布：全股票收购，隐含企业价值约 1150 亿美元，每股 Lumentum 换 4.5 股 Marvell（按 10 月 28 日收盘价约 1132 美元/股、溢价约 23.9%），合并后 Marvell 股东约占 67%、Lumentum 股东约占 33%；预计 2028 年上半年完成，须股东与监管批准，监管阻挠导致失败时 Marvell 付 32 亿美元分手费。消息公布当日 Marvell 股价跌 13%、Lumentum 跌 19%，市场并不买账。

为什么值得知道：这是今年 AI 基建最大的一笔“买光学”交易——逻辑是集群内互联从铜转光、共封装光学（CPO）省电；但 1150 亿是按固定换股比算的快照价，Marvell 股价每跌一分、交易总价就缩一分，别把它当成现金出价。

来源：[Barron's（11 月 2 日）](https://www.barrons.com/articles/stock-movers-987f3c90)、[TSN Media（11 月 2 日）](https://tsnmedia.org/marvell-lumentum-acquisition/)

**2. Oracle 再筹 200 亿美元：约 100 亿债券 + 100 亿股权，继续为 AI 基建烧钱**

Barron's 与 TechStartups 11 月 2 日报道：Oracle 披露此前宣布的 200 亿美元融资计划细节，约 100 亿美元债券加 100 亿美元股权，用于 AI 基础设施扩张；消息公布当日 Oracle 股价跌 8.8%。背景是 OpenAI 融资目标同期从 300 亿砍到 200 亿美元、估值目标从 1.4 万亿降到 1.25 万亿美元（报道口径、未确认）。

为什么值得知道：算力扩张的钱正从“股权故事”转向“债 + 股一起上”——债券占比越高，对现金流的要求越硬；这轮基建周期里，盯一家公司的发债规模，比盯它发布会上的 GPU 数字更能判断它还能烧多久。

来源：[Barron's（11 月 2 日）](https://www.barrons.com/articles/stock-movers-987f3c90)、[TechStartups（11 月 2 日）](https://techstartups.com/2026/11/02/top-tech-news-today-november-2-2026-the-biggest-stories-in-ai-startups-and-big-tech/)
