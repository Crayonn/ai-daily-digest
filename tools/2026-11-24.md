# AI 工具日报 2026-11-24

## AI 工具类

**1. Claude Code v2.1.331 发布：Code Mode 接入四大云平台，`claude doctor` 能测 API 连通性了（11 月 23 日）**

11 月 23 日发布的 v2.1.331 让 Code Mode 在 Bedrock、Google Cloud、Microsoft Foundry 和 AWS Claude Platform 上都能跑，`claude doctor` 新增 API 可达性检测。

为什么值得知道：企业用户不用再被锁在单一云厂商的 Claude 接入方式里，排障也从猜变成可测。

来源：[Havoptic 版本记录（11 月 23 日）](https://www.havoptic.com/releases/claude-code/2026/11)

**2. OpenCode 2.4.0 发布：内置桌面浏览器 + 定时自动化 + 视频生成（11 月 23 日）**

11 月 23 日发布的 OpenCode 2.4.0（30 天内第 14 个版本）带来三大功能：内置桌面浏览器（可导入 Chrome/Edge/Firefox/Safari 的登录态与历史、装扩展）、Automations（定时/cron/MCP 事件触发 agent 跑任务）、generate_video（接视频模型的 provider 可直接在 agent 里出视频）。

为什么值得知道：开源 agent 正在把浏览器、定时任务、视频生成收进同一个 CLI，免费本体 + 按模型付费的路线对重度用户越来越划算。

来源：[OpenCode 官方 Changelog（11 月 23 日）](https://opencode.ai/changelog?area=desktop,core)

**3. Qwen Code 0.28.4 发布：Web Shell 加工作区产物库，内置 Gemini 4 推理默认值（11 月 22 日）**

11 月 22 日发布的 Qwen Code 0.28.4 给 Web Shell 加了工作区 artifact 库页面（渐进扫描、流式更新），核心层加入 Gemini 4 推理默认值。

为什么值得知道：Qwen Code 30 天内发了 17 个版本，是目前迭代最快的开源 coding agent 之一，Web 端体验正在追平桌面 CLI。

来源：[AgentVera changelog](https://agentvera.dev/en/agent-changelog/)

**4. 提醒：Gemini 4 Carbon 12 月 1 日起涨价一倍，$2/$10 的体验价只剩一周**

Google 官方定价页显示，Gemini 4 Carbon 11 月 30 日前为 $2/$10 每百万 token（输入/输出），12 月 1 日起涨到 $4/$20，翻倍；Cursor 内同款模型同价，同款 Claude Fable 5.2 为 $8/$40。

为什么值得知道：正在用 Gemini 4 Carbon 跑量大的任务，这周是最后的半价窗口，12 月后同量成本直接翻倍。

来源：[Apidog 定价核查（11 月 23 日）](https://apidog.com/blog/gemini-4-carbon-pricing/)
