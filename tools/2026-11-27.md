# AI 工具日报 2026-11-27

## AI 工具类

**1. GitHub Copilot 代码评审计费规则变了：12 月 30 日起默认组织买单，平均每次评审 Lite $0.25 / Balanced $1.50 / Max $10（11 月 25 日）**

GitHub 宣布：从 12 月 30 日起，Copilot 代码评审对持牌成员默认按组织计费（未保存选择的情况下）；管理员选"成员自付"可维持现状。GitHub 估算平均每次评审成本：Lite 档约 $0.25、Balanced 档约 $1.50、Max 档约 $10。

为什么值得知道：以前"顺手点个评审"没人算账，12 月 30 日后每次评审都可能进组织的账单；评审量大的团队现在就该定好档位与默认计费方，别等账单来了再查。

来源：[1AYM AI 新闻（11 月 25 日）](https://www.1aym.com/news)

**2. Claude Code v2.1.328/329：云厂商上也能开 auto mode，/tasks 可列出循环任务（11 月 19–20 日）**

Claude Code v2.1.328：auto mode 现在支持 Amazon Bedrock、Google Cloud Agent Platform、Microsoft Foundry 与 Claude apps gateway 上的 Claude Opus 4.6 / Sonnet 4.6；v2.1.329：`/tasks` 可列出循环任务，并修配置与登录相关问题。此前一周的版本还包括实验性 Code Mode（2.1.323，Claude 改写 JavaScript 调工具而非逐个调用）与插件版本范围。

为什么值得知道：在 Bedrock/Foundry 上跑 Claude Code 的团队终于能用 auto mode；Code Mode 仍是实验功能，想试的先在小项目上开。

来源：[TierPatch（11 月 20 日）](https://www.tierpatch.com/new/#pn-2026-11-20-openai-codex-0-171-0)、[Oday Bakkour 周报](https://oday-bakkour.com/blog/ai-coding-tools-roundup-week-of-november-9-2026)

**3. Codex CLI 0.171.0：GPT-6.2 Sol 成默认模型，TUI 工作区默认开启（11 月 20 日）**

Codex CLI 0.171.0：GPT-6.2 Sol 与 Astra 进入模型目录，Sol 成为默认选择；TUI 工作区默认开启，支持可搜索的文档预览、图片预览与 subagent 对话记录。

为什么值得知道：Codex 用户升级后默认模型就变了——Sol 是便宜档（API 价 $2/$10），日常任务成本会下来，但重推理任务要记得手动切回 Astra。

来源：[TierPatch（11 月 20 日）](https://www.tierpatch.com/new/#pn-2026-11-20-openai-codex-0-171-0)

**4. Claude Code Trace v0.20.0：Codex 会话也能浏览与估算成本了（11 月 17 日）**

Claude Code Trace 0.20.0 新增 Codex 作为一等会话来源：桌面、网页、终端三端都能浏览、打开、检查 Codex 会话，并按 token 数与 API 价估算成本（明确标注是 API 费率估算、不是订阅账单）；同时支持 resume/fork 命令一键复制，Jev 效率分析也扩展到 Codex 会话。该集成默认关闭、只读，需在设置里手动开启。

为什么值得知道：同时用 Claude Code 与 Codex 的用户，终于可以在一个地方对账两个工具的成本与效率；估算值带"A+"标记表示已知不完整，别直接当账单用。

来源：[Undercode News（11 月 17 日）](https://undercodenews.com/claude-code-trace-v0200-just-made-codex-a-first-class-session-source-with-cost-tracking-and-ai-efficiency-analysis-video/)

**5. Google Workspace MCP 正式可用：2027 年 2 月 1 日起 agent 必须走官方 MCP，但现在还发不了邮件（11 月 24 日）**

Google 的 Workspace MCP 服务器与 CLI 正式可用；从 2027 年 2 月 1 日起，AI agent 访问 Workspace 数据必须经过这些官方服务器。付费 Scaled 档从 2027 年 4 月 1 日起计费。需要注意：目前的 MCP 服务器缺少关键功能——比如不能发 Gmail；新的 AI Tools Addendum 限制 agent 能保留什么数据，管理员可以允许、设门控或屏蔽外部 agent。

为什么值得知道：还有两个多月过渡期，但"发不了邮件"这个缺口不补上，很多自动化流程 2 月 1 日会直接断掉；现在就该按官方 MCP 重接一遍、列出缺失功能清单。

来源：[1AYM AI 新闻（11 月 24 日）](https://www.1aym.com/news)、[The Token Reporter（11 月 26 日）](https://tokenreporter.ai/)
