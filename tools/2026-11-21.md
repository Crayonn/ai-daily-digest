# AI 工具日报 2026-11-21

## AI 工具类

**1. Claude Code v2.1.330（11 月 21 日）：危险操作前强制确认回归，另有 easel 图表模块与企业控制台登录；v2.1.328/329（11 月 19 日）改了 /code-review 的汇报范围**

最新版 2.1.330（11 月 21 日，142 项 CLI 改动）：系统提示词新增"三思而后行"规则——危险操作前须经用户确认；内置 easel 图表模块；企业版管理控制台可登录；修了长对话压缩后数分钟卡死的问题。2.1.329（11 月 19 日）：`/tasks` 纳入本会话的定时任务、`/loop` 唤醒、目标与对话分支，按 x 可逐个停；新增 hooks 声明位置的信任提示；macOS 电脑操作收紧安全规则（部分动作会被拒绝、部分应用权限收窄）；`/code-review` 无目标时默认评审整个分支相对默认分支的差异。2.1.328（11 月 19 日）：`/code-review` 在多数模型上只报 bug 与 CLAUDE.md 违规，复用与简化类清理改走 `/simplify`；mcp_tool hook 新增 onFailure；Opus 4.6 / Sonnet 4.6 在 Bedrock、Google Cloud Agent Platform、Microsoft Foundry 与 Claude apps gateway 上支持 auto mode。

为什么值得知道：2.1.330 的确认规则是安全侧的回摆——先升到 2.1.330 再干活；`/code-review` 只报 bug 意味着想顺手做重构清理的人要改用 `/simplify`，否则评审结果会"变少"。

来源：[Gradually Claude Code 变更日志](https://www.gradually.ai/en/changelogs/claude-code/)、[AGI Hunt 2.1.330 事件页（11 月 21 日）](https://agihunt.info/en/e/1a1fb31d2e37d0a82a9cedbd6ad)、[Claude Code 官方变更日志](https://code.claude.com/docs/en/changelog)

**2. OpenAI 公开 Performance Factory：Codex agent 自动查 ChatGPT 变慢，3 个多月跑了 1700+ 次调查、找到 600+ 个根因**

OpenAI 11 月 19 日发文介绍内部系统 Performance Factory：性能告警一响就建任务，Codex agent 按 `perf-forensics` 技能调查变慢原因（查指标、部署、配置变更、读代码、对日志与 trace），写出修复建议交工程师评审；部署后另一个 agent 检查性能是否回到基线。关键设计是"对抗评审"：第二个 Codex 会话拿全新上下文挑战诊断、测反事实，约四分之一的诊断会被打回重查。3 个多月里 Regression Workflow 跟踪 1700+ 次调查、平均每天 17 次，600+ 起找到根因、约 400 起由 Codex 提交修复；人工抽查 100 条根因建议，70% 被评为准确。系统由任务服务、派发循环、云端 Codex 执行 API 与事件订阅四部分组成，agent 以专用服务身份、受限权限运行。

为什么值得知道：这是头部实验室把"agent 运维 agent"的流程完整公开的第一份作业——任务状态机 + 对抗评审 + 人工拍板的三段结构，任何跑 agent 做运维的团队都能直接抄；70% 准确率也说明这类系统现阶段仍需人工兜底。

来源：[OpenAI 官方博客（11 月 19 日）](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)

**3. Google Gemini Tasks 免费开放（11 月 17 日）：常驻 agent 可代打电话订位、比价下单，6 国免费用**

Google 11 月 17 日把 Gemini Tasks（前身 Spark Beta / Task Mode）向美、日、韩、加、澳、印六国免费开放，底层为 Gemini 4 Hydrogen；在 Gemini 应用里把顶部开关从 Chat 切到 Tasks 即可。能力：找附近商家并同时打多家电话、订位、写入 Google Calendar；比价、下单并用 Google Pay 结账（须用户确认、可设消费上限）；读 Gmail 找日程、接 60+ 常用应用。高级能力（打电话、Google Pay 支付、代登录网站）初期只在美国开放，且美国 5 个州（印第安纳、路易斯安那、明尼苏达、蒙大拿、内布拉斯加）不支持电话功能；免费档用量上限未公布。

为什么值得知道：这是第一个向数亿免费用户开放的"能动手办事"的 agent——此前这类常驻 agent 只在 Pro/Ultra 付费档；美国用户今天就能让它代打电话订位，是当天可亲测的 agent 功能；但 Google 自己也提醒任务可能失败，订位与付款务必人工复核。

来源：[TechCrunch（11 月 17 日）](https://techcrunch.com/2026/11/17/google-expands-access-to-gemini-tasks-which-can-help-with-calls-purchases/)、[Neowin（11 月 17 日）](https://www.neowin.net/news/google-makes-its-always-on-ai-agent-free-adds-phone-calls-shopping-and-more/)

**4. ChatGPT Live Dictation 上线（11 月 18 日）：边说边出字，10 分钟录音上限取消，全套餐可用**

OpenAI 11 月 18 日起在全球推 Live Dictation：点消息框麦克风，说话时文字实时出现在屏幕上，可随时点波形显隐字幕、说完先编辑再发送；此前 10 分钟录音上限取消（未公布新上限）。覆盖 iOS、Android、网页与桌面端，全部套餐含免费版，分批推送中、部分账号尚未见到。隐私注意：消费级账号若开着"改善模型"音频分享，口述音频可能被用于训练；商务账号默认不参与；相关开关在设置 → 数据控制里（"Include your audio recordings"）。

为什么值得知道：长提示词终于可以"说"而不是"打"了，对写长需求、头脑风暴最实用；但默认分享音频的设置值得先检查一次再长时间口述。

来源：[Digital Trends（11 月 19 日）](https://www.digitaltrends.com/computing/chatgpt-now-supports-live-dictation-openai-removes-the-10-minute-recording-limit/)、[Notebookcheck（11 月 20 日）](https://www.notebookcheck.net/ChatGPT-Live-Dictation-removes-the-10-minute-limit-for-all-plans.1455249.0.html)
