# AI 工具日报 2026-11-17

## AI 工具类

**1. Goose 1.59.2（11 月 16 日）+ Qwen Code 0.27.4（11 月 15 日）：两家都在补托管 agent 的安全边界**

Goose 1.59.2：Databricks provider 不再把属于其他前缀的 thinking block 带进来；当周连发两版（1.59.1 同日）。Qwen Code 0.27.4：托管 agent 会话可访问授权的本地目录、可开交互式托管 Web 终端（不持久化凭证与路径）；输出可推到飞书与企业微信 webhook；Auto Mode 对高风险动作改为必须显式授权，并可见地标记 Full Access；Web Shell 目标页可合并可信工作区的目标。

为什么值得知道：两家都在补"托管 agent 的安全边界"——Goose 修的是 provider 串数据，Qwen Code 修的是高风险动作要人点头；Qwen Code 30 天发 16 版，迭代速度是这批 CLI 里最快的。

来源：[AgentVera 版本追踪（11 月 16 日更新）](https://agentvera.dev/en/agent-changelog/)
