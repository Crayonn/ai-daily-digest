# AI 工具日报 2026-11-26

## AI 工具类

**1. Claude Code v2.1.332 发布：MCP 服务器能下发 skill（beta），新增 skill 命令拦截 hook（11 月 25 日）**

Claude Code 2.1.332：MCP 服务器可直接下发 skill（beta），在 `/` 菜单里显示为 `server:skill`；新增 `PreSkillShellCommand` hook，可在 skill 或命令加载内联 shell 命令时直接拒绝；另修 93 处 bug，包括命名管道读不到内容时无限挂起（现 20 秒超时）、本地 MCP 服务器刷爆标准输出导致终端卡死及 Ctrl+C 失效、hook 输出过大撑爆上下文（超约 50,000 字符自动截断）。本次共 150 处改动。

为什么值得知道：skill 从此有了两个来源（本地文件 + MCP 服务器），分发更方便；但 hook 拦截也说明 Anthropic 在补"第三方 skill 悄悄跑 shell 命令"的安全缺口——装陌生 MCP 服务器前先看它下发什么 skill。

来源：[Claude Code 官方 Changelog（11 月 25 日）](https://code.claude.com/docs/en/changelog)、[TurboAI（11 月 25 日）](https://www.turboai.dev/blog/claude-code-env-vars-v2-1-332)

**2. Gemini 4 Neon 进入 GitHub Copilot GA：定位 agentic coding，单任务 token 成本低于 Carbon（11 月 25 日）**

Gemini 4 Neon 现已在 GitHub Copilot 中正式可用，定位是 agent 式编程、多步工具调用与知识工作；按 Google 的说法，质量接近 Gemini 4 Carbon，但每个任务的 token 成本更低。

为什么值得知道：Copilot 用户多了一个中端模型选项——Neon API 价 $3/$15 每百万 token，比 Carbon 涨价后的 $4/$20 还便宜，日常 agent 任务可以先拿它当默认。

来源：[BriefPanel（11 月 25 日）](https://briefpanel.com/radar/ai-coding-tools-changelog)

**3. 微软 Copilot 解绑 M365 + Copilot Workspaces + Agent 365 支出分析（Ignite，见今日早报）**

微软在 Ignite 上宣布新客户用 Copilot 不再强制先有 Microsoft 365 订阅；同时推出 Copilot Workspaces 与 Agent 365 Business Analytics（追踪 AI 支出），Foundry 接入 GPT-6.2 与 Meta 模型。

为什么值得知道：采购门槛降低之外，Agent 365 的支出分析直接回应了"agent 花了多少钱没人知道"的痛点，企业上 agent 前先看它。

来源：[AI Briefing（11 月 25 日）](https://www.aibriefing.dev/)

**4. Cognition 发布 SWE-2.1：Devin Desktop 与 CLI 免费到 12 月 8 日（11 月 24 日）**

Cognition 为 Devin 发布 SWE-2.1 模型，Devin Desktop 与 CLI 用户免费使用至 12 月 8 日。

为什么值得知道：免费窗口只有两周，想对比 Devin 与 Claude Code/Codex 的用户可以在这段时间内零成本实测同一任务。

来源：[BotsDoThat（11 月 25 日）](https://botsdothat.com/news/)

**5. Google Antigravity 新增 Mass Spec Skills：帮科学家解读串联质谱、辅助分子鉴定（11 月 25 日）**

Google DeepMind 为 Antigravity 用户推出 Mass Spec Skills 工具，解读串联质谱（tandem mass spectra）以辅助鉴定分子。

为什么值得知道：Antigravity 的 skill 开始进入垂直科研场景——不是通用助手，而是"会读质谱的实验助手"，科研类 agent 的分工正在变细。

来源：[The Token Reporter（11 月 25 日）](https://tokenreporter.ai/)

**6. Goose 1.61.0 发布（11 月 25 日）**

Block 的开源 agent CLI Goose 更新至 1.61.0（当日版本汇总确认，详细改动见官方 release）。

为什么值得知道：Goose 是少数"自带 key、任意厂商模型"的主流开源 agent CLI，版本节奏稳定（30 天内 10 个版本），适合不想被单一订阅锁定的用户。

来源：[AgentVera（11 月 25 日更新）](https://agentvera.dev/en/agent-changelog/)

## AI 视频类

**1. Kling 3.0 上线：15 秒单条＋原生音频，1080p 含音频约 $0.13–0.16/秒（11 月 25 日核价）**

Kling 3.0 是快手的新一代视频模型：单条最长 15 秒、原生音频（含对白），1080p 含音频约 $0.13–0.16/秒（按套餐不同）；入门 Standard 套餐 $8.80/月。横向对比：同是 1080p 含音频，Veo 3.1 Fast 与 Runway Gen-4.5 均为 $0.12/秒，Kling 3.0 贵一点，但单条时长几乎翻倍。

为什么值得知道：要一次出 15 秒带声画的镜头，Kling 3.0 是目前唯一的主流选择；只做 8–10 秒短镜头的话，Veo Fast/Gen-4.5 更便宜。

来源：[FreshSynapse（11 月 25 日核价）](https://freshsynapse.com/articles/best-ai-video-generators-2026-11-25/)、[UltraGamerZ（11 月 24 日更新）](https://www.ultragamerz.com/best-ai-video-generators-2026/)

**2. Veo 3.1 Fast 与 Runway Gen-4.5 同价 $0.12/秒（1080p 含音频）；Veo 3.1 Standard $0.40/秒**

按 11 月 25 日核价：Veo 3.1 Standard $0.40/秒（720p/1080p 含音频，4K $0.60/秒）；Fast 版 $0.10–0.12/秒；Lite $0.05–0.08/秒。Runway Gen-4.5 为 12 credits/秒、$0.12/秒，Gen-4 Turbo $0.05/秒；消费端 Standard $15/月（年付 $12/月），625 credits 约 52 秒 Gen-4.5。

为什么值得知道：中端价位已经收敛到 $0.12/秒，选型不用再比单价，比的是单条长度（Veo 8 秒、Runway 10 秒、Kling 15 秒）与控制能力。

来源：[FreshSynapse（11 月 25 日核价）](https://freshsynapse.com/articles/best-ai-video-generators-2026-11-25/)

**3. Google Flow 倒计时：Veo 3.1 Fast／Quality 与 Omni Flash 1.1 将于 12 月 5 日退役（剩 9 天）**

Flow 内 Veo 3.1 Quality/Fast 与 Omni Flash 1.1 标注 12 月 5 日退役，之后 Flow 只剩 Omni Flash 1.2 与 Veo 3.1 Lite；Veo Extend 已于 11 月 5 日退役。Omni 1.1 的 API 请求 12 月 3 日起自动转到 1.2，按 1.2 价格计费。

为什么值得知道：还在用 Veo 3.1 Quality（Flow 内 100 credits／8 秒）做片的用户须在 12 月 5 日前完成重跑或迁移到 Omni 1.2／Veo 3.1 Lite。

**4. Gemini API 的 Veo 3.1 Preview 已于 10 月 22 日关闭，官方改推 Gemini Omni Flash**

Google 的 Gemini API 视频文档已说明 Veo 3.1 Preview（Standard/Fast/Lite）于 10 月 22 日关闭，开发者改走 Gemini Omni Flash（`gemini-omni-1.2-flash`）：3–15 秒片段、原生音频、可对话式编辑，720p 约 $0.07/秒、1080p 约 $0.104/秒。Veo 的正式落点现为 Google Cloud（Vertex AI），API 价 $0.40/秒（含音频）。
