**3. Claude Code v2.1.309（10 月 22 日，纯修复）**：macOS/Linux 沙盒 Bash 启动文件绕过、`denyWrite` glob 经 symlink 失效、可自动接受的编辑能改 MCP 配置文件——一连串"agent 能摸到不该摸的文件"类修复，无新功能。为什么值得知道：重度用户建议升级；agent 沙盒逃逸是本周第二起（配合 METR 报告看）。来源：[gradually.ai](https://www.gradually.ai/en/changelogs/claude-code/)

**4. Google 发布 Gemini API CLI 实验预览（v0.4.3）**：零依赖 Go 二进制、Apache 2.0 开源；任何有 shell 的 coding agent 凭 `GEMINI_API_KEY` 一条命令调用文本/图/视频/音乐/语音生成、文件与 YouTube 分析、音视频转写、Deep Research；媒体直接落盘只回传路径（不污染 context）。为什么值得知道：Google 给所有 coding agent（Claude Code、Codex、Cursor…）递的"多媒体外挂"，agent 做视频/转写任务不用各家各自接 API。来源：[AICoder](https://aicoder.com/news/news-20261022-google-gemini-api-cli-gemini-api-preview-coding-agents)
