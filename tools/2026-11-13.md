# AI 工具日报 2026-11-13

## AI 工具类

**1. Gemini 4 Hydrogen（11 月 12 日）：谷歌的"执行层"模型，每百万 token 输入 1.50 美元，Search 全量用户直接用上**

谷歌发布 Gemini 4 Hydrogen，接替 Gemini 3.8 Flash：1M 上下文、全窗口统一定价——输入 1.50 美元/百万 token、输出 7.50 美元/百万 token；四档思考级别（low/medium/high/xhigh），Artificial Analysis 智能指数默认 51 分、xhigh 达 54 分，略高于 Argon 的 50 分；Terminal-Bench 4.1 得分 57%，对 3.8 Flash 的 18.2%，谷歌称任务完成速度快 2.5 倍。当天起在 Gemini API、AI Studio 全档、Gemini App、Google Search（全部用户）与 Antigravity（Pro/Ultra 订阅）上线；Antigravity 还新增 Orchestrator 模式（Carbon 规划 + Hydrogen 执行），仅 Ultra 可用。注意 Cloud 文档里的一句：Hydrogen 是"短期正式版"，退役最少只提前 45 天通知，且不支持 RAG Engine、微调与 Live API。

为什么值得知道：对跑 agent 的人，1.50 美元的价位 + 57% 的 Terminal-Bench 分是目前"便宜且能干活"的新基准；但"短期版 + 45 天退役通知"意味着别把它钉进长期流程，至少留一个可替换的模型位。

来源：[Google 官方博客（11 月 12 日）](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)、[CellCog（11 月 12 日）](https://cellcog.ai/blog/gemini-4-flash-release-date/)

**2. Claude Code 2.1.323（11 月 12 日）：实验性 Code Mode，让 Claude 写 JavaScript 来调工具**

Claude Code 发布 2.1.323：实验性 Code Mode——Claude 直接写 JavaScript 来调用工具；插件开始支持版本范围；validate 能抓 TypeScript hook 的问题。Codex CLI 最新仍为 11 月 11 日的 0.167.2，Gemini CLI 最新仍为 11 月 10 日的 0.68.0，11 月 12 日均无新版（AgentVera 11 月 12 日更新）。

为什么值得知道：Code Mode 是 Claude Code 执行方式的一次换挡——从"一次调一个工具"变成"写一段程序批量调工具"，长任务的工具调用开销直接降下来；但它是实验性功能，先在非关键任务上试，别直接上生产流程。

来源：[Havoptic（11 月 12 日）](https://www.havoptic.com/whats-new/claude-code)、[AgentVera（11 月 12 日更新）](https://agentvera.dev/en/agent-changelog/)

**3. Databricks 第二代 Genie（11 月 11 日）：常驻后台的企业 agent，Ontology 已 GA**

Databricks 发布第二代 Genie：常驻后台的企业 agent，有目标就自己接手——按计划或触发器跑任务、派 subagent、追缺失的输入、到人决策时才找人；底层是 Genie Ontology（自动维护"公司怎么运转"的横向上下文：定义、指标、人与流程），搜索覆盖 100+ 企业数据源（Google Drive、Jira、Confluence 等）。Genie 与 Ontology 已 GA，常驻模式与 Genie Search 在 preview/beta；Genie One 免费到 2027 年 1 月 31 日。自家评测称 Genie 任务通过率 91%，对两个匿名对手的 58%（厂商自测，未经独立验证）。

为什么值得知道：企业 agent 的竞争从"问答"打到"常驻"——谁能在后台替你把活干完、只在要决策时找你，谁就赢了；但注意常驻模式还在 preview，91% 这个数也是 Databricks 自己测的，落地前先在小范围跑两周再看。

来源：[Databricks 官方（11 月 11 日）](https://www.databricks.com/company/newsroom/press-releases/databricks-launches-new-always-genie-autonomous-ai-complex)、[The Neuron（11 月 12 日）](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-thursday-november-12-2026/)

**4. AlphaGenome 2 API（11 月 11 日）：DNA 变异预测下放到细胞类型，非商业研究已开放**

DeepMind 发布 AlphaGenome 2 并开放 API（非商业研究；商业研究 private preview）：预测 DNA 变异如何影响具体人类细胞类型，在 1.07 亿多个单细胞画像上训练；TenK10K 数据集上因果变异识别率从 16% 提到 30%。后续还将发布 AlphaGenome 2 Skills 到 Google Antigravity，与 Gemini 4 组成"agent 科学工具"。

为什么值得知道：做基因组、药物靶点的人可以直接拿 API 验假设，不用自己训模型；Antigravity 的 skills 意味着"科学 agent"正在从聊天变成可编排的工具链，下一波 agent 落地可能先出现在实验室而不是办公室。

来源：[Google DeepMind 官方博客（11 月 11 日）](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)

**5. Google Labs Tabletop（11 月 12 日）：一句话生成协作空间，美国 waitlist**

Google Labs 推出 Tabletop：用提示词生成可定制的协作空间——行程、AA 制记账、晚餐投票、锦标赛签表等，可邀请他人实时协作。目前仅限美国成年人 waitlist。

为什么值得知道：这是"提示词 → 可用产品"又一次落到协作场景——不是生成一段文字，而是一个能多人同时用的工作区；对做小工具、做模板的人，这是最值得抄的形态：一个提示词 = 一个带状态的共享页面。

来源：[The Neuron（11 月 12 日，转述 The Verge）](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-thursday-november-12-2026/)

**6. n8n 推出 Nod（11 月 12 日）：开源个人 agent，用你自己的 Mac/PC 在应用与网站里干活**

n8n 扩展 agent 产品线，推出 Nod：开源个人 agent，在 Mac 或 PC 上的私人电脑里运行，在应用与网站里替你操作；与 n8n 原有的可视化自动化平台互补。

为什么值得知道：个人 agent 正在分两条路——云端代办（OpenAI、Meta 的助手）与本地私人电脑（Nod 这类）；后者的卖点是"你的电脑、你的数据"，代价是你得自己有一台一直开着的机器。对不想把账号密码交给云端助手的人，这是值得试的另一条路。

来源：[The Neuron（11 月 12 日，转述 Product Hunt）](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-thursday-november-12-2026/)
