# AI 工具日报 2026-10-26

## AI 工具类

**1. Claude Code 2.1.310（10 月 25 日实测版本）：并行 agent 进入 agent view**

AI Parabellum 10 月 25 日在 macOS 上用 Claude Code v2.1.310 实测并行 agent：`claude agents` 打开 agent view 面板，`claude --bg "任务"` 派发后台会话，每个会话在独立 git worktree 里改代码；空格键 peek、回车进入会话。作者明确标注 agent view 仍为研究预览、按键与界面可能变化，且每个会话单独消耗额度。

为什么值得知道：并行 agent 的卖点不是"同时跑"，而是"互不踩文件"——worktree 隔离是选型时要问的第一件事；但额度按会话叠加，并行一时爽、账单也要按会话数算。

来源：[AI Parabellum（10 月 25 日）](https://aiparabellum.com/claude-code-parallel-agents/)

**2. Codex 0.163.0：Daybreak 重新成为默认，沙箱加预 DNS 权限检查**

据 10 月 18 日当周的 Claude Code/Codex/Gemini CLI 周报：Codex 0.163.0 把 Daybreak 重新设为符合条件账号的默认（扭转 0.161.0 的改动），并对限制网络访问的沙箱做了预 DNS 权限检查；同周 Claude Code 方面，闲置对话自动压缩（20 万 token 以上闲置约 54 分钟后压缩），可用 `"idleCompaction": false` 关闭。

为什么值得知道：Daybreak 默认与否、沙箱 DNS 检查这类"默认项改动"最容易在升级后悄悄改变 agent 行为——升级前先看一周周报，比事后查日志便宜。

来源：[dev.to 周报（10 月 17 日，覆盖 0.163.0）](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-october-18-2026-e6d)

**3. Peras：给 Claude Code 与 Codex 加"硬上限 + 暂停键"的免费工具（10 月 21 日）**

Peras（MIT 开源）读取 Claude Code 与 Codex 的本地用量数据，不碰登录文件、不存 prompt：可设每日额度、按项目文件夹与用量百分比设限；三种干预模式为提醒、人工确认、硬暂停；macOS 有原生菜单栏应用；`peras review` / `peras compare` 可做周度用量复盘。Codex 一侧经本地 app-server 读数，与 Claude 用量历史分开。

为什么值得知道：订阅制 agent 的真正成本不是月费而是"周中撞墙"——一个能在撞墙前硬暂停的工具，比事后看账单有用；且"不存 prompt、不碰登录文件"是这类工具必须先交代的信任点。

来源：[ClawdBytes（10 月 21 日）](https://www.clawdbytes.com/article/2026-10-21-show-hn-peras-pause-claude-code-and-codex-before-they-burn-your-weekly-limit)
