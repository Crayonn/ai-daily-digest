# AI 工具日报 2026-11-11

## AI 工具类

**1. Claude Code v2.1.322（11 月 10 日）：Vertex 上也能开 fast mode，拒绝时自动回落标准速度**

Claude Code 升至 v2.1.322：fast mode 登陆 Google Vertex AI 的 global、美国与欧盟区域；若 Vertex 拒绝 fast mode，会话自动回落标准速度、不报错。同期 Gemini CLI 升至 v0.68.0（见第 2 条），两家同一天发版。

为什么值得知道：fast mode 此前是 Anthropic 自家 API 的卖点，现在 Vertex 托管的 Claude 也能开——对走 GCP 合规路线的团队，这意味着"快 2.5 倍"不再与"用 Anthropic 直连"绑定；回落机制则保证了速度是加分项、不是故障点。

来源：[Havoptic Claude Code 更新日志（11 月 10 日）](https://www.havoptic.com/tools/claude-code)、[Updatify 发布记录（11 月 10 日）](https://updatify.io/releases/claude-code)

**2. Gemini CLI v0.68.0（11 月 10 日）：Windows 路径更顺、限流倒计时、免 root 的 Podman 沙箱**

Gemini CLI 升至 v0.68.0：一批修复——Windows 路径处理更平滑、加载指示器里加限流倒计时、支持免 root 的 Podman 沙箱。Claude Code 同日升至 v2.1.322（见第 1 条），两家主流 coding agent 同一天发版。

为什么值得知道：三处改动全是"每天都会碰到的小摩擦"——Windows 路径、限流等待、沙箱权限；coding agent 的竞争已经从"模型谁强"下沉到"谁的日常体验少卡一下"，版本号本身成了风向标。

来源：[Havoptic 对比页（11 月 10 日）](https://www.havoptic.com/compare/claude-code-vs-gemini-cli)

**3. Claude Fable 5.2 进 GitHub Copilot（11 月 10 日）：复杂多步编码任务可直接用新旗舰**

Anthropic 的 Fable 5.2 于 11 月 10 日在 GitHub Copilot 全面可用，可用于跨大型代码库的复杂多步编码任务；同期也已上架 Amazon Bedrock 与 AWS 上的 Claude Platform。Fable 5.2 定价 8/40 美元每百万 token（输入/输出）、缓存读取 0.20 美元，上下文 100 万 token。

为什么值得知道：Fable 5.2 发布次日即进 Copilot，说明"最强模型"与"最常用入口"的结合速度正在加快；对 Copilot 用户，这次不用换工具就能试新旗舰在自家代码库上的真实表现——Remote Labor Index 41.3% 的成绩单（见早报第 6 条）正是在这类任务上拿到的。

来源：[RC Labs 每日简报（11 月 10 日）](https://daily.rclabs.in/d/2026-11-10)

**4. Claude Sheets / Whiteboards / Data / Meetings（11 月 10 日）：Claude 长出表格、白板与数据连接**

Anthropic 同日发布四件套：Claude Sheets（带公式、多标签页）、Claude Whiteboards（头脑风暴白板，Claude 总结）、Claude Data（原 Dashboards 改名，接 Snowflake 与 Salesforce）、Claude Meetings（Claude 加入会议并在讨论中开始工作，Team 与 Enterprise beta）。Interactive Connectors 让 Adobe、Atlassian、Salesforce 把应用嵌进 Claude；企业版另得审计日志、隔离虚拟机与合规 API。

为什么值得知道：这是 Claude 第一次把"对话"扩成"工作台"——表格与白板是微软与谷歌的基本盘，Anthropic 敢正面打，赌的是"agent 替你填表、做总结"比"人自己填"更有吸引力；对订阅用户，Sheets 与 Whiteboards 的 beta 是最值得先试的两项。

来源：[The Neuron（11 月 11 日）](https://www.theneuron.ai/news/google-anthropic-openai-ai-assistants-workspaces/)

**5. OpenAI 在 ChatGPT 里推商家功能（11 月 10 日）：企业资料、互动数据与卖家 agent**

OpenAI 推出 ChatGPT 内的 Businesses 功能：商家可建企业资料、看聚合互动数据，并部署面向客户的卖家 agent；Business Hub 为 beta，卖家 agent 先面向符合条件的美国电商与在线服务商家。这是 OpenAI 在 AWS Marketplace 上架 ChatGPT Enterprise（11 月 9 日）之后的第二步企业化动作。

为什么值得知道：ChatGPT 正在从"问答入口"变成"商家门面"——用户在里面不只聊天，还能直接对接卖家；对中小商家，这等于多了一个不用自己建站的获客渠道，对 OpenAI 则是把"企业版订阅"之外的第二条变现线。

来源：[The Neuron（11 月 11 日）](https://www.theneuron.ai/news/google-anthropic-openai-ai-assistants-workspaces/)

**6. Adobe 把 Creative Cloud 向第三方 agent 开放（11 月 10 日）：MCP 直连 Photoshop 等原生文件**

Adobe 在 MAX 大会上预览本地 MCP 集成：OpenAI、谷歌与 Anthropic 的第三方 agent 可直接编辑 Photoshop、Illustrator、Premiere 与 After Effects 的原生项目文件，每层、每段序列保持可编辑，人可中途接手；另预览常驻后台 agent 与 Firefly 助手的 Plan Mode。私人 beta 定于 2027 年初。

为什么值得知道：Adobe 的打法与别家相反——不把 agent 关在自家围墙里，而是把自家文件格式开放给所有 agent；对创作者，这意味着"用哪个 agent"与"用什么软件"第一次解绑，工具选择权回到人手里。

来源：[SiliconNoon（11 月 10 日，转述 The Verge）](https://siliconnoon.com/today-in-ai-november-10-2026/)

## AI 视频类

**1. Kineo 实测 1430 次渲染：Seedance 1.5 是真正能出片的引擎，Veo 3.1 与 Kling 2.5 已下架（11 月 11 日）**

Kineo 公布 90 天生产数据：1430 次真实渲染中，Seedance 1.5 完成 804 部 60 秒成片（712 人），每部 35 credits、约 4.43 美元、中位 5.9 分钟；MiniMax H3 为 45 credits、约 5.70 美元、7.4 分钟；Seedance 2.5 为 150 credits、约 19 美元、16.8 分钟。Veo 3.1（仅 3 部）与 Kling 2.5（仅 5 部）已于 11 月 5 日从 Kineo 引擎列表下架。

为什么值得知道：这是少有的"按成片算账"而非"按演示打分"的横评——Seedance 1.5 赢的不是画质，是"便宜、快、能做完"；批量出竖屏短片的人，先按这个成本表选引擎，再按榜单选模型，顺序别反了。

来源：[Kineo（11 月 11 日）](https://www.usekineo.com/seedance-vs-veo-vs-kling)

**2. Veo 3.1 停用倒计时 6 天：11 月 17 日起 Google Cloud 模型页提示停用**

Veo 3.1 已于 10 月 22 日从 Gemini API 下线，Google 推荐改用 Gemini Omni Flash；Veo 3.1 Fast 与 Lite 仍在 Google Cloud 上可用，但 11 月 17 日起模型页将提示停用，距今只剩 6 天。

为什么值得知道：还在用 Veo 3.1 出片的人只剩不到一周窗口——11 月 17 日之后要么切 Omni Flash、要么接受 Cloud 端的变化；依赖 Veo 3.1 做固定流程的团队现在就该测好替代模型的出片效果，别等停用当天再换。

来源：[Slash Digital 视频模型横评（11 月更新）](https://slash-digital.io/en/insights/video-models-2026/)、[Convly（11 月 8 日更新）](https://convly.ai/best-ai-video-generators-2026/)

**3. Kling 4.0 在 Runway 八折到 11 月 30 日：720p 每秒 0.157 美元 → 约 0.126 美元**

Runway API 上的 Kling 4.0（720p 0.157 美元/秒、1080p 0.235 美元/秒）八折持续到 11 月 30 日；Kling 4.0 自 10 月 15 日全量开放，单条最长 30 秒、带立体声，支持最多 10 个关键帧。

为什么值得知道：要长镜头（20–30 秒）又不想付 Veo 价，11 月底前是 Kling 4.0 最便宜的窗口；但注意这是 Runway 渠道价，Kling 官方至今未公布自己的开发者 API 定价。

来源：[Forasoft 文生视频 API 对比（11 月 8 日复核价）](https://www.forasoft.com/blog/article/text-to-video-api-comparison)

**4. 同一条 8 秒 720p 片子，报价能差 16.8 倍：Seedance 2.5 最贵 3.03 美元，Veo 3.1 Lite 只要 0.18 美元（11 月 9 日横评）**

11 月 9 日的 API 横评显示：同一条 8 秒 720p 片子，Kunavo 10 月 9 日的价格表从 Veo 3.1 Lite 的 0.18 美元到 Seedance 2.5 的 3.03 美元，相差 16.8 倍；Revana 10 月 19 日的目录价则为 Seedance 2.5 约 0.21 美元/秒、Seedance 2.0 约 0.15 美元/秒，同一模型在不同渠道的报价能差近两倍。

为什么值得知道：视频 API 的价差不在模型之间，而在"渠道 × 时长计费 × 音频附加费 × 重试损耗"之间——先定死自己的硬需求（时长、分辨率、要不要声），再在同一个渠道口径下比价，比逐家看榜单省钱得多。

来源：[AI Reiter 视频 API 横评（11 月 9 日）](https://aireiter.com/blog/best-ai-video-generation-api-2026)

**5. MiniMax H3 走 fal 渠道 480p 约 0.05 美元/秒：开源权重路线的最低价**

MiniMax H3 权重已上 Hugging Face，通过 fal 调用 480p 约 0.05 美元/秒；Wan 2.5 同价位也有 0.05 美元/秒的档。两者都是 11 月横评里"按秒计费最便宜"的选择，但分辨率与音画同步能力弱于 Omni 1.2 Flash 与 Veo 3.1。

为什么值得知道：批量出片、分辨率要求不高时，H3 与 Wan 2.5 的每秒价只有 Omni 的七成、Veo 的八分之一；先按"每秒价 × 成片秒数"算总账，再按榜单选模型，顺序别反了。

来源：[Convly（11 月 8 日更新）](https://convly.ai/best-ai-video-generators-2026/)
