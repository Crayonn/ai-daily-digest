# AI 工具日报 2026-11-08

## AI 工具类

**1. Claude Code 2.1.319（11 月 6 日）：auto mode 不再回落到内置分类器**

2.1.319 的改动影响面最大：telemetry 或 feature flags 关掉时（包括走 LLM 网关），服务器无法核查的调用会被问或拒绝，不再回落到内置分类器；无人值守新增 `permissions.denyInsteadOfPrompting`，直接拒绝而不是卡住等确认；可用 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 恢复旧行为（Bedrock、Vertex、Foundry 不受影响）。同批还有后台 MCP 任务与自动拒绝的权限提示。

为什么值得知道：走网关或关了 telemetry 的团队升级后会发现原来自动放行的调用开始弹窗——这是安全收紧，不是 bug；无人值守脚本要么开新开关、要么显式恢复旧行为，别等定时任务半夜卡住才发现。

来源：[TurboAI 发布分析（11 月 7 日更新）](https://www.turboai.dev/)、[DEV 周报（11 月 7 日）](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-8-2026-485k)

**2. Codex 0.167.0（11 月 6 日）：agent command center、Vertex AI 上手向导、后端切换**

Codex 正式版到 0.167.0：agent command center（多 agent 并行跑的控制台）、GCP Vertex AI 上手向导、后端切换；同日 0.169.0-alpha.2 已在测。10 月底的“28 天连发”收官后，这是 11 月第一个正式版。

为什么值得知道：command center 是 Codex 往“多 agent 编排”推的关键一步，配合 11 月 12 日断供 Cursor 的时间点，OpenAI 在把 Codex 从“一个终端 agent”升级成“能同时指挥一群 agent 的工作台”；Vertex 上手向导则说明它在抢 GCP 那边的企业用户。

来源：[TurboAI 发布分析（11 月 7 日更新）](https://www.turboai.dev/)、[发布追踪（11 月 6 日更新）](https://stackloom-ai.pages.dev/ai-coding-releases/)

**3. OpenCode 2 v2.2.6（11 月 7 日）：本周最活跃的开源工具又发一版**

OpenCode 2 正式版到 v2.2.6（11 月 7 日），一周内连发七版后又一版；OpenCode 1.x 停在 1.19.4（10 月 22 日）。它是本周发布最频繁的开源 coding agent。

为什么值得知道：发版频率本身就是信号——OpenCode 2 正在快速迭代期，追新功能的人可以跟正式版走，不用等 alpha；但一周七版也意味着接口可能跟着变，写进脚本的命令要留好回滚版本。

来源：[TurboAI 发布分析（11 月 7 日更新）](https://www.turboai.dev/)、[发布追踪（11 月 6 日更新）](https://stackloom-ai.pages.dev/ai-coding-releases/)

**4. Google Antigravity 加语音模式，NotebookLM Flashcards 也升级了**

Google 的 Antigravity coding agent 新增语音模式，由 Gemini Live 模型驱动；同一批更新里 NotebookLM 的 Flashcards 能带图了，还加了可选的计时器和移动端复习提醒。

为什么值得知道：语音模式是 coding agent 第一次把“边说边改代码”做进主流产品——开车、散步时口述需求再回来看 diff 的流程开始成立；NotebookLM 的小升级则是提醒：Google 在把学习类产品也往 agent 方向推，卡片不再是静态的。

来源：[The Daily Fledgling（11 月 7 日）](https://thedailyfledgling.click/)

**5. ChatGPT Remix 上线 Business/Enterprise：看到同事做的网站，直接改一份自己的**

ChatGPT 的 Remix 功能向 Business 与 Enterprise 账号推出：看到同事做的网站，直接说改哪、改完继续在同一个对话里编辑自己的副本。OpenAI 的定位是“同事刚发了个好东西，你 inevitably 有修改意见”的下一步。

为什么值得知道：这是 ChatGPT 从“个人聊天”往“团队协作画布”走的一步——网站不再是一次性生成物，而是团队里可以互相 remix 的半成品；对做内容、做落地页的人，Remix 比从头生成省一半时间。

来源：[The Daily Fledgling（11 月 7 日）](https://thedailyfledgling.click/)

**6. OpenAI 开发者侧：Showcase tab 上线，Pro/Business 用户可领 API credits**

OpenAI Developers 推出 Showcase tab，并邀请符合条件的 ChatGPT Pro 与 Business 订阅用户在账单设置里领取 API credits；另有 GIF 模式（配合 Images 2.6 的动态图能力）。

为什么值得知道：订阅用户白拿 API credits 是真金白银——Pro 用户现在去账单设置里看一眼就能领，等于订阅费里多了一笔 API 额度；Showcase tab 则说明 OpenAI 在把开发者生态往“可展示、可发现”推。

来源：[The Daily Fledgling（11 月 7 日）](https://thedailyfledgling.click/)

**7. Claude Code 云端会话可自建环境：开工前自己把 repo 搭好**

Claude Code 的云端会话（Pro、Max、Ultra）现在可以自行完成环境搭建再开工，不用用户先配好；配合 2.1.319 的后台 MCP 任务，云端 agent 的自主性又往前走了一步。

为什么值得知道：云端 agent 最大的摩擦一直是“环境配不好就开不了工”——自建环境把这一步也自动化了，意味着把 repo 链接丢给 Claude、等它自己搭环境、跑任务、开 PR 的流程更接近可用；但环境搭建的每一步仍要留好审计，别让它在云端装了不该装的东西。

来源：[The Daily Fledgling（11 月 7 日）](https://thedailyfledgling.click/)

**4. DeepSeek V4.1 Flash 推理速度：GB300 上每 agent 848 tokens/秒**

DeepSeek V4.1 Flash 在英伟达 GB300 NVL72 上每 agent 解码速度达 848 tokens/秒，一个月前同一硬件上是 596；SGLang 内核优化后批量为 1 时达 873.6 tokens/秒（从 35 起步、25 倍）；超大规模配置下聚合吞吐超每 GPU 100 万 tokens/秒、成本约 0.002 美元/百万 tokens（超大规模定价场景，非一般部署）。

为什么值得知道：一个月 596→848，硬件没换，全是软件层优化的功劳——推理成本下降的速度比模型发布更快；但 0.002 美元/百万 tokens 是超大规模场景价，普通团队别按这个数做预算，按自己服务商的实际价目算。

来源：[Crypto Briefing（11 月 6 日）](https://cryptobriefing.com/deepseek-v4-1-flash-gb300-nvl72-speed/)、[SGLang 博客](https://www.sglang.io/blog/deepseek-v4.1-flash-kernel-optimization)
