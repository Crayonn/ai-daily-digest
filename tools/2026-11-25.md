# AI 工具日报 2026-11-25

## AI 工具类

**1. OpenAI Codex CLI 0.172.0 发布：多会话管理 + Tab 补全 + 内置 GPT-6.2 迁移指南（11 月 24 日）**

11 月 24 日发布的 Codex CLI 0.172.0：可跟随搜索结果/ transcript 里的 thread 链接直接打开保存的对话与嵌套 agent；斜杠命令支持 Tab 补全（如 `/mcp lo`→`/mcp login`）；agent command center 内 Shift+Up/Down 在任务组间跳转；stdio MCP 服务器首次调用时才启动；内置 `openai-docs` skill 增加 GPT-6.2 Astra/Sol 迁移指南。

为什么值得知道：终端里多会话管理成本下降，Tab 补全是每天都用得到的小改进；上一版 0.171.0（11 月 20 日）已把 GPT-6.2 Sol 设为默认模型。

来源：[ChatGPT 官方 Changelog（11 月 24 日）](https://learn.chatgpt.com/docs/changelog)、[ReleaseBot（11 月 24 日）](https://releasebot.io/updates/openai/codex)

**2. Gemini CLI v0.71.0 / v0.71.1 发布：修 Windows 下 UI 卡死，0.70 堵上 allowlist 绕过（11 月 24 日）**

Gemini CLI v0.71.0 修 PowerShell 命令异步解析导致的 UI spinner 卡死，v0.71.1 为补丁更新；v0.70.0（11 月 19 日）收紧 shell 策略匹配（只按顶层命令匹配 commandPrefix/commandRegex）、跳过权限不安全的系统 MCP 服务器、保留 Unicode 提示词。

为什么值得知道：0.70 的两处是安全类修复——allowlist 绕过被堵上；0.71 修的是 Windows 下的卡死，Windows 用户值得升。

来源：[Gradually Changelog（11 月 24 日）](https://www.gradually.ai/en/changelogs/gemini-cli/)、[Precis Daily（11 月 19 日）](https://precisdaily.com/article/google-gemini-cli-receives-v0-70-0-update)

**3. Claude Code：Fable 5.2 成默认 Fable 模型，v2.1.321+ 修 5 处权限/安全缺口**

Fable 5.2 成为默认 Fable 模型，1M 上下文，API 价 $8/$40 每百万 token，缓存读 $0.20/百万 token，输出比 Fable 5.1 快约 30%，需 v2.1.321+，`/model claude-fable-5-2` 切换；v2.1.321 修了 4 处权限/沙箱缺口，v2.1.325 修了 zstd 解码安全问题；`/usage` 按 `f` 可自动修用量占用项，`ultrathink` 单轮触发 xhigh 思考。

为什么值得知道：先升到 v2.1.321+ 再谈别的，4 个权限缺口 + 1 个安全修复是硬性项。

来源：[Dev.to（11 月 22 日当周整理）](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-15-2026-4pmm)、[Dev.to（Fable 5.2 详解）](https://dev.to/thecodestreet/claude-code-new-update-fable-52-ultrathink-15-features-explained-5g59)

**4. Anthropic：Skills over MCP 公开 beta，Tasks 与 Elicitation 正式可用（11 月 24 日）**

Anthropic 11 月 24 日宣布，Skills over MCP 在 Claude 与 Claude Code 中进入公开 beta，Tasks（后台长任务）与 Elicitation（中途向用户要输入）正式可用，File Uploads（文件直传 MCP 服务器）随后推出。连接的服务器可直接下发工作流指导、跑耗时任务、请求用户输入；Anthropic 称 MCP SDK 月下载超 7 亿次，Claude 已有 1 万多个 MCP 连接器。

为什么值得知道：MCP 从"调工具"升级为"发工作流 + 跑长活"，接 Shopify、HubSpot、Atlassian 这类服务器的体验会直接变好；这是 Claude 插件体系（见今日早报）背后的协议升级。

来源：[Unite.AI（11 月 24 日）](https://www.unite.ai/anthropic-brings-server-supplied-skills-and-background-tasks-to-claude/)

**5. Orca v1.4.269：bot 后端新增 Kiro、Kimi Code 等 8 个 agent（11 月 21 日）**

Orca v1.4.269 的 bot 后端新增 Kiro、Kimi Code、Auggie、Gemini CLI、Kilo Code、MiMo Code、Droid、Goose 共 8 个 agent；Orca 本身是在不同 git worktree 里并行跑多个终端 coding agent 的桌面界面。

为什么值得知道：一个界面管 8 家 agent，后端越全，并行对比同一任务的不同解法越方便；该项目当日 GitHub 日增星 1,025（见下方排行）。

来源：[MindPattern（11 月 21 日）](https://www.mindpattern.ai/e/gemini-cli)

**6. OpenCode v2.4.1：修 macOS 12 旧版 SQLite 存不上消息；v2.3.2 修 GPT-6.2 prompt 缓存重复计费**

v2.4.1（11 月 23 日）修 macOS 12 上 SQLite 旧版导致 assistant 消息存不上，仅写在配置里的 provider（如 Ollama）无需 `/connect` 登录即可在 `/models` 显示模型；另 v2.3.2 修了 GPT-6.2 prompt 缓存问题——系统提示每步重复计费，Copilot 上 GPT-6.2-Sol 每步未缓存输入从约 14,000 token 降到 3。

为什么值得知道：缓存修的是真金白银——每步 14,000 token 的重复计费修成 3 个，用 GPT-6.2 跑 OpenCode 的用户升级即省钱。

来源：[OpenCode 官方 Changelog（11 月 23 日）](https://dev.opencode.ai/changelog?area=core,extensions)、[Gradually Changelog](https://www.gradually.ai/en/changelogs/opencode/)
