# AI 工具日报 2026-11-18

## AI 工具类

**1. OpenCode 1.19.6 + Qwen Code 0.28.0（11 月 17 日）：OpenCode 2.0 升级入口来了，Qwen Code 接钉钉**

OpenCode 1.19.6：OpenCode 1 内置升级到 2.0 的入口——2.0 在后台下载，装不装由你选（重启时升级、退出时升级、稍后），会话、项目与设置保留；会话图片超 25 MiB 时最老的图换占位符、不再发超大请求；provider 报错"请求体过大"时自动触发压缩重试。Qwen Code 0.28.0：托管 agent 频道加钉钉适配、Web Shell 侧栏加工作区筛选、循环开关可强制关（不只开）；30 天 17 版。

为什么值得知道：OpenCode 2.0 的升级做成了"可选、不断会话"，比强制大版本升级友好得多；Qwen Code 一个月 17 版，仍是这批 CLI 里迭代最快的。

来源：[AgentVera 版本追踪（11 月 17 日更新）](https://agentvera.dev/en/agent-changelog/)

**2. Claude Code 2.1.326（11 月 16 日）：全是"防呆"；Codex / Copilot / Gemini CLI 今日无新版**

Claude Code 2.1.326：agent teams 开启时也能开 Code Mode；--allowedTools 等参数里写得不像完整规则的值会在启动时警告；管理员中途加 managed-mcp.json 导致 MCP 停载时会有解释消息；/status 新增一行，说明哪些功能被 provider 或环境变量（如 DISABLE_TELEMETRY）关掉了。Codex CLI 仍为 0.169.0（11 月 13 日）、Copilot CLI 1.0.112（11 月 13 日）、Gemini CLI 0.68.0（11 月 10 日），今日无新版。Cursor 今日检索未发现新版本或价格变动。

为什么值得知道：这版没有新功能，全是帮团队排查"为什么我的功能没生效"——启动警告、停载解释、状态行；没新功能就不用追升级。

来源：[AgentVera 版本追踪（11 月 17 日更新）](https://agentvera.dev/en/agent-changelog/)

**3. MAI Code 2 与 Code 2 Flash 进 GitHub Copilot（11 月 17 日 Ignite 宣布）**

微软自研编码模型首次进 Copilot 模型池；官方称 Code 2 在企业编码基准上达到 GPT-6.1 Sol 98% 的能力、价格 40%，Opus 5.5 的 96%、价格 5%；Code 2 Flash 对标 GPT-6.1 Sol 的日常编码任务，价格分别为 GPT-6.1 Sol 的 65% 与 Haiku 5.5 的 20%。另推 MAI Licensed Weights，企业可在自有 Azure 环境定制部署。

为什么值得知道：Copilot 的模型池第一次有了微软自家的一线编码模型，价格锚直接对标 Claude 与 OpenAI；但百分比是微软自选基准篮子的自述，实际体验要等 Copilot 用户实测。

来源：[Thurrott（11 月 17 日）](https://www.thurrott.com/a-i/microsoft-ai/343999/ignite-2026-microsoft-ai-announces-7-new-models)

**4. OpenAI 两件小事：Dots 开始测试 1Password；20 万科学家免费名额 11 月 23 日开放申请**

据 TestingCatalog 11 月 17 日简报：OpenAI 开始在 Dots 里测试 1Password，用于需要登录的任务；另将向最多 20 万名科学家开放免费前沿模型访问，11 月 23 日开放申请。两件事都只有一个信源（简报转述），细节待官方公告。

为什么值得知道：Dots 接 1Password 意味着 agent 代办"要登录的活"正在补最后一块拼图；20 万科学家免费名额如果是真，是今年最大的一次研究者免费开放。

来源：[TestingCatalog 11 月 17 日简报](https://www.linkedin.com/company/testingcatalog)
