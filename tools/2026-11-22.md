# AI 工具日报 2026-11-22

## AI 工具类

**1. Claude 移动端改版：底部栏分出 Chat / Projects / Code / Artifacts（11 月 21 日）**

Anthropic 正在向 Claude 移动端推送新设计：底部导航栏分出 Chat、Projects、Code 与 Artifacts 四个入口，Code 指向移动端 coding agent 能力。改版与 Claude Code 2.1.330（11 月 21 日，危险操作前强制确认回归、内置 easel 图表模块）同属一轮产品更新。移动端 Code 入口意味着"手机上也能跑 Claude Code 会话"正在从 Remote Control 的附属能力变成一级入口。

为什么值得知道：手机端 coding agent 从"远程看看"变成"一级入口"，通勤与外出场景的 agent 使用门槛又降一档；等改版推到你的账号上，先看 Code 入口能调多少本地与云端能力。

来源：[TestingCatalog 每日简报（11 月 21 日）](https://www.linkedin.com/company/testingcatalog)

**2. OpenCode 2.3：后台子 agent，交代完就交还控制权、活在后台继续干（11 月 18 日）**

OpenCode 2.3 引入后台子 agent：派活后立即交还控制权，子 agent 在后台异步继续工作，完成后回来汇报；另有实验性 artifacts 支持。同一周的横评指出，这是 OpenCode 与 Claude Code、Codex 的分化点——Claude Code 的 Code Mode 与 agent teams、Codex 的多任务命令中心都在做"多 agent 编排"，OpenCode 选的是"不阻塞主会话"的轻量路线。

为什么值得知道：后台子 agent 解决的是"派了活就得等着"的老痛点——主会话继续干别的，后台任务慢慢跑；多 agent 编排正在成为三家 coding agent 的共同方向，选型时可把"后台任务管理"作为对比维度。

来源：[AI Tools Weekly（11 月 18 日）](https://www.joinnextdev.com/blog/ai-tools-weekly-claude-codes-agent-era-arrives-4-more-updates)

**3. Claude Code 2.1.327：/install-github-app 前先确认仓库变更，mcp 配置可从 stdin 读（11 月 18 日前后）**

Claude Code 2.1.327 的主要改动：/install-github-app 在动仓库级配置前先弹出确认步；新增 `claude mcp add-json <name>`，可从 stdin 读取 MCP 服务器配置、方便脚本化接入。2.1.325 还补了 Code Mode 对 agent teams 的支持与恢复会话的分隔线。同一周 Anthropic 连发 2.1.325–2.1.327 三个版本，方向一致：agent 编排能力往上加，仓库级动作的确认往上收。

为什么值得知道：装 GitHub App 这类"一动就动全仓库"的操作终于有了确认步——此前是 agent 直接改；mcp add-json 则让 MCP 配置可以脚本化批量下发，管多台机器的人能直接抄。

来源：[AI Tools Weekly（11 月 18 日）](https://www.joinnextdev.com/blog/ai-tools-weekly-claude-codes-agent-era-arrives-4-more-updates)

**4. Codex 0.169：exec 的信任规则收紧，不可信目录里 --sandbox workspace-write 也不再自动启用项目配置与 MCP（11 月 15 日当周）**

OpenAI Codex 0.169.0 改了 `codex exec` 的信任判定：即使加了 `--sandbox workspace-write`，在不可信目录里项目配置与 MCP 服务器仍保持禁用，须显式加 `--trust` 才会保存项目信任。0.168.0 与 0.169.0 的共同方向是"默认不信任"。同一周 Codex 还发了 0.167.1、0.167.2（Vertex AI 上工具更新改为增量发送）与 0.168.0。

为什么值得知道：以前一条 --sandbox 参数就能绕过信任检查，现在必须显式 --trust——在陌生仓库跑 codex exec 的脚本要改，否则 MCP 与项目配置会静默失效，先查信任状态再排查"为什么工具没加载"。

来源：[This week in Claude Code, Codex and Gemini CLI（11 月 14 日）](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-15-2026-4pmm)、[AI Tools Weekly（11 月 18 日）](https://www.joinnextdev.com/blog/ai-tools-weekly-claude-codes-agent-era-arrives-4-more-updates)

**5. Gemini 能用 Omni 1.2 Flash 生成 GIF：Google AI 订阅用户、首批 8 国**

Google 11 月 21 日起让 Gemini 用 Gemini Omni 1.2 Flash 生成 GIF，面向 Google AI 订阅用户、首批 8 个国家开放。Omni 1.2 Flash 11 月 5 日已在 Gemini API 全面可用（720p 约 $0.07/秒，3–15 秒、16:9 或 9:16），此前已在 LMArena 文生与图生视频双榜拿第一；GIF 生成是它"对话式改视频"能力的又一次下放。订阅用户今天就能在 Gemini 里直接试：让它把一段描述或一张图变成 GIF，顺手可发。

为什么值得知道：GIF 是社交传播的硬通货，视频模型一旦能直接出 GIF，"发帖配图"的生产链就短了一截；8 国首批名单未全公布，先看自己账号里有没有入口。
