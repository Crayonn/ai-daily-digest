# AI 工具日报 2026-11-06

## AI 工具类

**1. GPT-6 Cyber 进 Codex 与 API：只给通过审核的 Daybreak Red 客户**

OpenAI 11 月 5 日把 GPT-6 Cyber 开放给一小批 Daybreak Red 客户，经 API 与 Codex 调用，未来几周扩大到全部已批准客户；GPT-5.6 Cyber 也同步向全部 Daybreak Red 客户开放。配套的安全措施是硬性的：Daybreak Red 的 API 访问默认要求 IP 白名单，另有针对授权范围外活动的专项监控与高风险请求复核；防御侧另设 Daybreak Blue，验证漏洞与补丁时减少不必要的拒绝。

为什么值得知道：这是 Codex 第一次装进一个“会写 exploit”的模型，但门是焊死的——普通 Pro/Plus 用户完全碰不到；对安全从业者，真正的变化是 Daybreak 分了红蓝两条线：进攻研究走 Red、防御验证走 Blue，申请前先想清楚自己属于哪条线。

来源：[The Neuron（11 月 5 日）](https://www.theneuron.ai/news/openais-gpt-6-cyber-can-hack-better-can-it-stay-within-the-rules/)、[Cyber Security News（11 月 5 日）](https://cybersecuritynews.com/openai-launches-gpt-6-cyber/)

**2. Claude Marketplace 上架 25+ 合作 agent：企业能用 Anthropic 的预付款买第三方软件**

Anthropic 11 月 5 日给 Claude Marketplace 增加 25 个以上合作 agent 与产品，覆盖网络安全、开发基建与效率工具，包括 Datadog、Chainguard、Cyera；企业客户可以用已承诺的 Anthropic 预算额度直接采购这些第三方软件，按 committed-spend 结算。

为什么值得知道：这不是又上架一批插件，而是 Anthropic 在把自己的账单变成企业软件采购通道——已经向 Anthropic 承诺了预算的企业，现在买 Datadog 这类工具不用另走采购流程；对个人用户没直接变化，但它说明 Anthropic 的变现重心正在从“卖模型调用”转向“卖企业软件入口”。

来源：[AI Briefing（11 月 5 日）](https://aibriefing.dev/story/3e93342c42d6/)

**3. Conductor 被 Meta 收购：云服务 11 月 20 日关停，用着的人先导出数据**

Meta 11 月 4 日收购多 agent 编排工具 Conductor，团队并入 Meta Superintelligence Labs。现有用户的时间线：11 月 4 日起停新注册与下载、现有 Pro 功能免费保留；云服务 11 月 13 日只读、11 月 20 日关闭并开始删除云端数据；Mac 本地应用继续用到 2027 年初。

为什么值得知道：一天之内 OpenAI 收 Pierre、Meta 收 Conductor，头部实验室都在抢“多 agent 怎么组织”这一层；但对正在用 Conductor 云端跑任务的人，今天的动作只有一个——11 月 20 日前导出数据，过期不候。

来源：[PYMNTS（11 月 4 日）](https://www.pymnts.com/news/artificial-intelligence/2026/meta-acquires-ai-coding-startup-conductor/)、[CellCog（11 月 5 日）](https://cellcog.ai/blog/meta-acquires-conductor/)

**4. Postman Desktop 被曝未经用户同意装了 Claude Code 与 Codex 插件**

GitHub issue 披露，Postman Desktop 12.33.4 在用户不知情的情况下安装了 Codex 插件 1.1.0 与 Claude 插件 2.0.1，改动涉及 `~/.codex/config.toml`、`~/.claude/settings.json`（启用 postman@claude-plugins-official）与 `~/.claude/plugins/installed_plugins.json`，还装了一个 Postman CLI 到 `~/.local/bin/`。问题 10 月 25 日提交，11 月 3 日在 Hacker News 被顶起后发酵。

为什么值得知道：这不是功能争议，是边界问题——一个桌面应用在没有明确授权的情况下往你的 agent 配置目录里写东西；装过 Postman 的用户值得现在就查一下 `~/.claude/settings.json` 里有没有不认识的插件，删掉只要一行命令，但前提是你知道它在那。

来源：[GitHub issue（10 月 25 日提交，11 月 3 日发酵）](https://github.com/postmanlabs/postman-app-support/issues/14370)、[Medium 转述（11 月 4 日）](https://blurbrahlab.medium.com/claude-code-2-1-317-a14a209fff51)

**7. ChatGPT 与 Codex 12 月起共享 token 额度：Plus/Pro 用户先算好账**

OpenAI 已确认，从 12 月起 ChatGPT 与 Codex 编程工具将在付费计划内共享同一 token 额度；结合 10 月 26 日的 GPT-6.1 Terra 降价（输入/输出每百万 token 1/5 美元，是上一代的一半，缓存输入 0.05 美元），OpenAI 的算盘很清楚：模型越便宜，越要把聊天与编程的用量并到一个池子里算总账。

为什么值得知道：12 月前，ChatGPT 聊天和 Codex 写代码是两本账；12 月后是同一本账——重度 Codex 用户 12 月的账单结构会变，现在就该看一眼自己两边的用量，别等 12 月账单来了才发现额度被另一边吃掉了。

**8. Claude Code 三模型分工成官方玩法：一条命令同时用 Sonnet、Haiku、Opus**

Anthropic 的 advisor 功能正在 X 上刷屏：`claude --model sonnet --advisor opus` 启动后，Sonnet 5.5 跑主会话写代码，三个只读 Haiku 5.5 子 agent 并行搜库、找调用点、查文档，Opus 5.5 只在计划锁定前、同错两次后、收尾验收前三处出场；官方文档已上线 advisor 与 sub-agents 说明页。

为什么值得知道：这是官方给出的“好钢用在刀刃上”的标准答案——全程 Opus 太贵、全程 Sonnet 不够稳，分工后大判断有 Opus 兜底、日常消耗走 Sonnet 和 Haiku；对订阅用户来说，这比换更贵的套餐更划算，先改启动命令再谈升级。

Google 11 月 5 日让 Gemini Omni 1.2 Flash 全面可用：单段 3–15 秒（1.1 版上限 10 秒），720p 约每秒 0.07 美元，比 1.1 Flash 的约 0.10 美元降 30%；场景一致性与角色说话效果提升。Runway 同日把它接进编辑器，可按参考图生成、多轮对话改细节、升到 4K；Artlist、FLORA、Krea、Picsart 等也同步上架。

为什么值得知道：这张跌幅榜是判断 AI 基建股风险的速查表——跌得最惨的不是技术最差的，而是资产负债表最紧的；以后再看 AI 基建股，先看它借了多少钱、多少债要再融资，而不是先看它有多少张卡。
