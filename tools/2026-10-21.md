## 一、AI 工具类（coding agent / AI 应用）

**1. Simon Willison《Battle Drones》：一款浏览器 RTS 游戏全部由 coding agent 写成（10-20 博客）**

程序员 Simon Willison 发布了浏览器 RTS 游戏《Battle Drones》，12 个版本、321 个 commit 基本全是 coding agent 写的（从 7 月的 Claude Fable 5 起步，10 月切到 Opus 5.5）；关键一跃是开了 Claude Code 的 Ultracode 多智能体模式，让 Claude 自己打了 1,000+ 场 AI 对战调平衡——25 分钟难分胜负的对局从 14% 降到 0.9%。他坦言几乎没看过代码（TypeScript 他本来也不熟），但警告 Ultracode"烧 token 极快"。

为什么值得知道：这是"vibe coding 出真东西"的最新完整证据链——从"不好玩"到"好玩"的分水岭不是模型升级，而是让 agent 自己打 1,000 场对局做验证闭环；附完整版本历史、关键 prompt 和 transcript 链接，复刻成本低。

来源：[Simon Willison 博客（10-20）](https://simonwillison.net/e/9536)

**2. Claude Code v2.1.305（10-20）：Vertex/Bedrock 请求重试不再经过 tool search，Linux sandbox namespaces**

为什么值得知道：企业云部署（Bedrock/Vertex）用户升级后失败重试更快；sandbox 命名空间加固意味着本地隔离更安全。

来源：[TurboAI 更新记录](https://www.turboai.dev/)

**3. JetBrains Java-Kotlin 扩展进 RC：把 IntelliJ 级语言智能装进 VS Code / Cursor / Antigravity**

JetBrains 确认与 Cursor 团队直接合作，扩展进入 RC 阶段并扩大覆盖。

为什么值得知道：Cursor/VS Code 里写 Java/Kotlin 的补全和重构质量将向 IntelliJ 看齐，agent 能调用的语言能力也变强。

来源：[Shattered（10-20）](https://shattered.io/jetbrains-java-kotlin-vs-code-cursor-rc-2026/)

**4. UKG in Claude（10-20，beta）：基于 MCP 的连接器，让 Claude 直接查企业 HR/薪资系统**

决策者可用自然语言问"为什么这个区加班飙升"，Claude 能回答也能在权限内执行操作。

为什么值得知道：MCP 连接器正在从开发工具蔓延到企业核心系统——这是 Claude"工作场景"落地的又一块拼图。

## 三、AI 基础设施类

**1. 微软退出英国 Nscale Essex AI 数据中心（10-18 Telegraph 首报，微软 10-19 确认）**

原计划整租 50MW、部署约 23,000 张 Nvidia 芯片；英国电网称该站点通电要等到 2030 年代；Nscale 目标估值 350 亿美元，有投资人建议降到 160–190 亿。

为什么值得知道：AI 基建的瓶颈已经从"买不到卡"变成"接不上电"——4 月 OpenAI 也因电价/监管退出了 Nscale 的 Stargate UK 项目；同一周 Anthropic 还在洽谈第二笔 450 亿美元 Nscale 算力协议（见早报第一部分第 3 条），电力约束成了算力协议里的最大变量。

来源：[em360tech](https://em360tech.com/tech-articles/microsoft-nscale-uk-ai-data-centre-withdrawal)

**2. Cloudflare 内部 AI 代码评审推理账单砍 68%（10-19 官方博客）**

靠 prompt caching + 智能模型路由，单次 review 成本从 $2.43 降到 $0.77，中位耗时从 4 分 09 秒降到 1 分 32 秒。

为什么值得知道：大厂 FinOps 实战手册：先查"首请求是否命中缓存"，再谈模型选型——跑 agent 规模化的人可直接抄。

来源：[Cloudflare 官方博客](https://blog.cloudflare.com/obsessive-inference-optimization/)

**3. 字节/阿里/腾讯向 Nvidia 下超 350 亿美元订单（Reuters 10-20 独家）**

三家合计订购 300 万+ 张 RTX PRO 5500 工作站卡，单价约 $11,400；全中国客户订单超 600 万张，但 Nvidia 称 2027 年全球最多只能产 300 万张，可能只交付 5%–10%。

为什么值得知道：出口管制下中国大厂连工作站卡都抢不到——推理算力缺口比想象中大得多，直接利好 Nvidia 2027 年指引。

来源：[Reuters](https://www.reuters.com/business/retail-consumer/bytedance-alibaba-tencent-place-over-35-billion-worth-nvidia-chip-orders-2026-10-20/)（独家）
