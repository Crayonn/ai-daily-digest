# AI 工具日报 2026-11-19

## AI 工具类

**1. Codex CLI 0.170.0（11 月 18 日）：终端里打实时语音电话**

11 月 18 日发布的 rust-v0.170.0，在 TUI 内通过 WebRTC 协商实时语音通话；同时自动刷新 OpenTelemetry HTTP 导出器的认证头，同名 MCP 服务器在不同环境下实验性隔离。前一稳定版 0.169.0（11 月 13 日）已加多标签页侧边聊天（重启后保留）、Agent Command Centre 全文搜索、可折叠回合详情、`codex exec` 下 `--sandbox workspace-write` 不再单独启用项目配置/MCP。

为什么值得知道：Codex 正在从"打字写代码"变成"边说边改"的终端助手；0.169.0 的信任收紧是升级前必读项，旧脚本可能因配置不再自动启用而失败。

来源：[StackRank 版本追踪](https://stackrankhq.com/releases)

**2. Claude Code 2.1.327（11 月 17 日）：MCP 配置防误删，/status 变体检表**

最新版 2.1.327（11 月 17 日）：`/install-github-app` 改仓库前先确认；新增 `claude mcp add-json <name> -` 从 stdin 读服务器 JSON，token 不上命令行；`/status` 列出损坏的 agent / skill / 命令 / 输出风格文件、按键绑定错误、不可用沙箱、被忽略的权限设置和永不匹配的 hook；修复了项目级 `claude mcp add/remove` 会删掉 `.mcp.json` 其他顶级键的 bug。往前一周：2.1.323（11 月 12 日）加实验性 Code Mode（见今日早报第一部分第 9 条）；Fable 5.2 成默认模型，1M 上下文，$8 / $40 每百万 token，缓存读 $0.20；2.1.325（11 月 13 日）把沙箱内 Bash 改回默认走正常权限流程，并修 zstd 解码安全问题。

为什么值得知道：2.1.321 修了 4 处权限/沙箱缺口、2.1.325 又收紧一次——先升到 2.1.327 再干活；Code Mode 和 Fable 5.2 是本周唯二值得试的功能点。

来源：[Gradually Claude Code 变更日志](https://www.gradually.ai/en/changelogs/claude-code/)

**3. OpenCode 2.3.2（11 月 18 日）：跟进 GPT-6.2，缓存系统提示**

OpenCode 当天连发 2.3.1、2.3.2（11 月 18 日），2.3.1 接入 GPT-6.2、超时命令继续后台跑，2.3.2 缓存 GPT-6.2 系统提示。AgentVera 汇总：Gemini CLI 最新仍是 0.68.0（11 月 10 日，加扩展校验命令和评估测试）。

为什么值得知道：OpenCode 是当天发版最勤的开源 coding agent，GPT-6.2 上线次日即跟进；Gemini CLI 个人免费已于 6 月 18 日停掉、只剩付费 API / Code Assist，别再按免费版去试。

来源：[VibeStackLab 新版汇总](https://vibestacklab.com/new)、[AgentVera 版本追踪](https://agentvera.dev/en/agent-changelog/)

**4. VS Code 1.147（11 月 18 日）：Agent 请求能定时发送、能进真浏览器**

11 月 18 日稳定版：Send Later（实验性）可定时发送本地 agent 请求，也可用自然语言让 agent 安排；Drafts（实验性）可存多个未发送请求；Model routers（实验性）按任务自动选模型；Browser Use（预览）让 agent 操作用户自己的 Chrome / Edge（需 Copilot 浏览器扩展、Node.js 22+）；管理员可用策略放行 Claude / Codex harness。Local harness 已废弃、2027 年 2 月移除；同时停止支持 macOS Ventura / Sonoma 和 32 位 ARM Linux。

为什么值得知道：这是 VS Code 从"编辑器+Copilot"转向"agent 工作台"的一版，定时任务+真浏览器操作直接对标 Claude Code / Codex 的工作流；但 Send Later 不唤醒睡眠电脑、只对本机 session 生效。

来源：[VS Code 1.147 更新日志](https://code.visualstudio.com/updates/v1_147)

**5. GitHub Copilot Evals 进入公开预览，Copilot 进 Xcode（11 月 17 日）**

11 月 17 日，GitHub Copilot Evals 进入公开预览；同日 Copilot 加入 Xcode 内置编码助手；GPT-6.2 Astra / Sol 同日也在 Copilot 全面可用。

为什么值得知道：Evals 让团队能量化"换模型到底变好还是变坏"，正好接 MAI Code 2 / GPT-6.2 的选型；Xcode 用户不用再绕 VS Code。

来源：[StackRank 版本追踪](https://stackrankhq.com/releases)

## AI 视频类

**今日无全新模型发布。** 11 月 18 日没有 Veo / Kling / Runway / Wan 的新模型或新功能上线；以下为 11 月当月已确认的横评与价格，供选型参考。

**1. 横评：Kling 4.0 与 Wan 3.0 并列第一，Seedance 2.5 最贵**

11 月 1 日 45 条盲测（Hermoso）：Kling 4.0 与 Wan 3.0 同以 3.8/5 并列第一，领先 Seedance 2.5、MiniMax H3、Veo 3.1；Kling 4.0 最差一条仍有 3.6 分、最稳。11 月 16 日更新的 9 模型对比（WaveSpeed）：Seedance 2.5 与 Kling 4.0 仍是最强全能选择，两者单条都可达 30 秒带声音；Wan 3.0 同样 30 秒、每秒更便宜。

为什么值得知道：要稳、要长镜头，首选 Kling 4.0；要便宜量大，Wan 3.0 是同等长度下的低价替代；Seedance 画质不差但最贵，别当默认项。

来源：[Hermoso](https://hermoso.ai/research/best-ai-video-generator/)、[WaveSpeed](https://wavespeed.ai/blog/posts/ai-video-generation-models-2026/)

**2. 每秒价格（720p，厂商/聚合平台 11 月 7–16 日复核价）：Veo 最贵，Wan 最便宜**

Veo 3.1 $0.40/秒（含音频，4K 档 $0.60/秒）；Seedance 2.5 约 $0.36/秒；Kling 4.0 $0.157/秒；Runway Gen-4.5 $0.12/秒（API，12 credits/秒，无音频）；Wan 3.0 $0.10/秒；Gemini Omni 1.2 Flash $0.07/秒。换算 5 秒 720p 一条：Veo 3.1 $2.00、Seedance 2.5 约 $1.80、Kling 4.0 $0.79、Wan 3.0 $0.50、Omni Flash $0.35。注意：Veo 3.1 Fast 档更便宜，PicX 11 月 11 日核查 5 秒 720p 为 $0.77；Kling 4.0 在 Runway 上 11 月 30 日前 8 折（64 credits，之后 79）。

为什么值得知道：同一条 5 秒片，Veo 3.1 标准档的成本接近 Wan 3.0 的 4 倍——画质优先才选 Veo，量产/试错优先选 Wan 或 Omni Flash；Kling 4.0 的 Runway 折扣 11 月 30 日到期。

来源：[ForaSoft](https://www.forasoft.com/blog/article/text-to-video-api-comparison)、[WaveSpeed](https://wavespeed.ai/blog/posts/ai-video-generation-models-2026/)、[PicX（11 月 11 日核查）](http://picxstudio.com/blog/ai-video-api-price-index-november-2026)

**3. 长度与形态：30 秒已成新标配，Sora 彻底出局**

Kling 4.0（10 月 15 日全量，单条 3–30 秒、立体声、最多 10 关键帧/15 参考素材）、Seedance 2.5、Wan 3.0 均支持单条 30 秒；Veo 3.1 仍为 4/6/8 秒、最高 4K+原生音频；Runway Gen-4.5 为 2–10 秒、720p、无音频。OpenAI Sora 应用已于 2026 年 4 月 26 日关闭、API 于 9 月 24 日关闭，无替代上线；Google 已于 10 月 22 日下线 Gemini API 里的 Veo 3.1 预览，开发者改走 Gemini Omni Flash 或 Google Cloud 企业平台。

为什么值得知道：做 30 秒一镜到底的叙事，现在不用再拼剪——Kling 4.0 / Wan 3.0 / Seedance 2.5 都行；还在教程里写 Sora / Gemini API 版 Veo 3.1 的，一律过期。

来源：[Convly](https://convly.ai/best-ai-video-generators-2026/)、[GeekBlog](https://geekblog.net/ai-software/best-ai-video-generators-2026/)

**5. Cerebras 拆分式推理投产：GPU 做 prefill、晶圆级芯片做 decode，称每兆瓦吞吐 5 倍**

11 月 17 日宣布拆分式推理（disaggregated inference）投产：AMD Instinct GPU 处理提示词（prefill），Cerebras CS-3 系统负责生成 token（decode）；在 11 月 14 日 GPT-OSS-120B 共享端点上，称比纯 CS-3 配置每兆瓦吞吐高 5 倍、生成速度不降。早期合作方为 AWS、Fireworks AI、Gimlet Labs、General Compute；计划到 2027 年底部署数百兆瓦，另有 700MW 数据中心容量规划。

为什么值得知道：推理成本的下一个降价来源可能不是更便宜的 GPU，而是"prefill 与 decode 分家"这种架构重组；5 倍是 Cerebras 自测（自家基线、单端点），别直接当成全行业结论。

来源：[AIDose](https://www.aidose.in/news/cerebras-launches-disaggregated-inference-gpus-prefill)、[LetsDataScience](https://letsdatascience.com/news/cerebras-launches-production-disaggregated-inference-pairing-037f57dd)
