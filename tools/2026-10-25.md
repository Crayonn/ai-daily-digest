# AI 工具日报 2026-10-25

## AI 工具类

**1. Agent Skills 正式"去 Anthropic 化"：捐给 Linux 基金会旗下 AAIF（10 月 22 日）**

Anthropic 把 Agent Skills 标准连同名字、logo、GitHub 组织、agentskills.io 域名捐给 Agentic AI Foundation（AAIF，Linux 基金会旗下，此前已接手 MCP）。官方数字：70 多个 agent 平台已接入（ChatGPT、Cursor、GitHub Copilot、VS Code 等），100 万个 skill 已发布，近 2.8 亿次安装；后续由 Anthropic、谷歌、OpenAI 等工程师以个人身份维护。

为什么值得知道：一个"文件夹 + SKILL.md"的文件格式，正在成为跨 agent 的通用插件标准——你今天给 Claude Code 写的 skill，明天大概率能直接给 Codex、Cursor 用；且捐赠后不再是一家公司的私产，值得长期投入。

来源：[Anthropic 官方博文](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)

**2. Grok Bot 会做"活页面"了：报告、备忘、仪表盘可自动更新（10 月 21 日）**

据 xAI 官方 @bot 账号，Grok Bot 现在能生成报告、备忘与仪表盘页面，用户可以和它一起编辑，也可以让它持续保持页面最新。未公布适用套餐与价格，公开 changelog 当时最新仍是 10 月 14 日的 v0.71.2。

为什么值得知道：Bot 正在从"问答助手"变成"常驻协作者"——页面能自己更新，意味着它开始接管那些以前必须人盯着的周报、看板类活；但没给价格与可用范围，先别按它排工作流。

来源：[Tesla News Wire（10 月 21 日）](https://teslanewswire.com/articles/grok-bot-reports-memos-dashboards-live-pages-xai-oct-21-2026)

**3. AWS Infinity 与谷歌 Agent Substrate：agent 托管的"闲置成本战"开打（10 月 22–23 日）**

AWS 开源 Infinity（agent 挂起时几乎不占资源，单线程 8 万 agent、闲置约 100KB/个）；谷歌开源 Agent Substrate（GKE 上的同类运行时，20 万 agent 测试 500 激活/秒、挂起恢复低于 500 毫秒），其托管版 Agent Compute Engine 未来几个月才开放预览。

为什么值得知道：两家云厂商同一周给出同一个答案——长期运行的 agent 不能按"一直开机"收费，闲置必须便宜；自建 agent 基础设施时，"挂起成本"应成为选型指标之一。

来源：[AWS News Feed](https://aws-news.com/article/2026-10-23-introducing-infinity-a-runtime-for-extreme-agent-concurrency)、[AppStack Insider](https://appstackinsider.com/insights/google-cloud-launches-agent-compute-engine-for-ai-agents/)

## AI 视频类

**1. Veo 3.1 预览关闭，Gemini Omni Flash 1.1 接替（10 月 22 日）**

谷歌 10 月 22 日关闭 Gemini API 上的 Veo 3.1 预览模型，指定 Gemini Omni Flash 1.1 为替代（3–10 秒短片、原生音频）。Runway Dev 10 月 24 日价格快照：Veo 3.1 仍标 $0.40/秒、Fast 版 $0.15/秒；Kling O3 标准/专业/4K 分别为 $0.13 / $0.17 / $0.43/秒；Wan 3.0 支持 2–30 秒。

为什么值得知道：API 侧的模型换代比产品页更快——走 API 跑视频的工作流要盯住"预览关闭"这类公告，否则一夜之间端点就没了；按秒计价下，8 秒一条的成本在 $1–$3.2 之间浮动，选模型先算秒价。

来源：[tech-insider（10 月 24 日价格快照）](https://tech-insider.org/gemini-ai-video-generator-omni-flash-api-cost-ledger-2026/)

**2. 横评口径（10 月）：Veo 3.1 仍是最强短片，Kling 3.0 是性价比默认项**

LMArena 图生视频榜 Veo 3.1 以 1,397 Elo 领先；Artificial Analysis 文生视频榜 Kling 3.0 以 1,251 分领先，且片长接近 Veo 两倍并有免费每日档；Runway Gen-4.5 + Aleph 2.0 则赢在"改已有 footage"的编辑类。Kling 4.0 已于 10 月 15 日发布，但开发者 API 尚未定价。

为什么值得知道：没有全能冠军——要"一条 8 秒高光 + 原生对白"选 Veo，要"量大便宜"选 Kling，要"改片"选 Runway；Kling 4.0 先观望 API 价再动手。

来源：[trendintech 横评](https://trendintech.com/veo-3-1-vs-kling-3-0-vs-runway-gen-4-5-2026/)

## AI 基础设施类

**1. Meta Q3：营收 $64.6B 同比 +26%，全年 capex 指引抬到 $135–145B，自由现金流转负**

Meta 10 月 21 日财报：Q3 营收 646 亿美元（超预期的 633 亿），单季 capex 349 亿美元，全年 capex 指引下限从 1300 亿抬到 1350 亿美元；Q3 自由现金流 -$21.2 亿美元（Q2 为 +$7.84 亿）。Muse agent 美加 1 个半月建号超 1000 万，约 25% 建号用户每天使用。

为什么值得知道：AI 基建投入已大到让一家年赚数百亿的公司单季现金流转负——这是全行业"算力军备竞赛"的账本版；Muse 的 1000 万建号数则是这笔投入目前唯一的 C 端回音。

来源：[AI Parabellum（财报拆解）](https://aiparabellum.com/meta-q3-earnings-ai-spending-muse/)

**2. DeepSeek 约 $15B 融资：中资产业资本组团进场（10 月 22 日，彭博经 TechCrunch）**

约 1000 亿人民币融资，宁德时代、腾讯为最大投资方，另有吉利、美的等产业资本；目标额谈判中两次上调。资金用于数据中心与开源模型、备战国内 IPO。

为什么值得知道：这轮不是 VC  syndicate，而是电池、汽车、家电、芯片的产业联盟——DeepSeek 的算力与落地场景正在被中国制造业"包养"，后续开源模型的迭代速度值得盯。

来源：[TechCrunch](https://techcrunch.com/2026/10/22/deepseek-reportedly-raises-15b-days-after-us-restrictions/)

**3. 英国 AI 生物安全实验室：政府 £100M 现金 + 两家 lab £200M 模型额度（10 月 24 日）**

见早报第一部分第 2 条。路透称整个一揽子约 £600M，含 £65M 病原体对策资金。

为什么值得知道：政府采购 AI 的新范式——现金只占一小部分，大头是 lab 的模型额度；算力与模型正在变成"准财政"工具。

来源：[Golden Era（引 GOV.UK 与 BBC）](https://goldenera.si/news/uk-ai-biosecurity-lab-100-million/)

**4. AWS TorchNeuron：PyTorch 代码改一行配置就能跑 Trainium（10 月 19 日发布、20 日公开 beta）**

AWS 旗下 Annapurna Labs 推出 TorchNeuron（Apache 2.0 开源）：把 `.to('cuda')` 换成 `.to('neuron')`，现有 PyTorch 代码无需重写即可跑在 Trainium2/Trainium3 上，支持 eager、torch.compile 与 FSDP 等分布式接口；30 多家早期用户（含 Cartesia、Deepgram）已先行测试，Hugging Face 已原生支持 Trainium。

为什么值得知道：英伟达最深的护城河不是芯片而是 CUDA 生态——TorchNeuron 直接拆这堵墙；但亚马逊未公布独立性能数据，"能跑"不等于"跑得一样快"，等真实迁移案例再下判断。

来源：[Motley Fool（10 月 19 日）](https://WWW.FOOL.COM/investing/2026/10/19/amazon-torchneuron-nvidia-cuda-moat/)、[Pondero（发布细节）](https://pondero.ai/news/2026-10-20-aws-torchneuron-trainium-pytorch/)
