**2. Claude Code v2.1.326/2.1.327（11 月 16–17 日）：MCP 配置防误删，/status 变体检表**

最新版 2.1.327（11 月 17 日）：`/install-github-app` 改仓库前先确认；新增 `claude mcp add-json <name> -` 从 stdin 读服务器 JSON，token 不上命令行；`/status` 列出损坏的 agent / skill / 命令 / 输出风格文件、按键绑定错误、不可用沙箱、被忽略的权限设置和永不匹配的 hook；修复了项目级 `claude mcp add/remove` 会删掉 `.mcp.json` 其他顶级键的 bug。2.1.326（11 月 16 日）启动时警告 `--allowedTools` / `--disallowedTools` / `--tools` 里不完整的工具规则，并提示设置文件保存失败。再往前：v2.1.319 把 MCP task 后台化、新增 `permissions.denyInsteadOfPrompting`（无人值守时直接拒绝而非弹窗）；v2.1.316 上线 pooled group budgets（小组共享月度预算）与 cost-report 管理员 API。另注意：Opus 4.8 的 fast mode 将于 11 月 30 日移除，需迁到 Opus 5.5。

为什么值得知道：2.1.321 修了 4 处权限/沙箱缺口、2.1.325 又收紧一次——先升到 2.1.327 再干活；跑无人值守 agent 的人，`denyInsteadOfPrompting` 与小组共享预算是本周最实用的两处改动。

来源：[Gradually Claude Code 变更日志](https://www.gradually.ai/en/changelogs/claude-code/)、[VibeShelf 2026-W45](https://vibeshelf.co/shipped/2026-w45/)
