# AI 工具日报 2026-11-14

## AI 工具类

**1. Claude Meetings 上线 beta（11 月 12 日）：Claude 进 Google Meet 开会，边聊边做文档**

Anthropic 在 Team 与 Enterprise 计划上 beta 推出 Claude Meetings：Claude 以可见参与者身份加入 Google Meet，记笔记、答问题、会中直接做文档与白板；只保留文字记录与屏幕描述，不存音频；笔记与文字记录 beta 期免费，会中产出物免费至 2027 年 2 月 10 日；Team 默认开启、Enterprise 默认关闭；零数据留存、HIPAA、客户自管密钥的组织暂不可用；目前仅支持 Google Meet，其他平台称"即将推出"，未给时间。

为什么值得知道：会议记录员这个活，Claude 终于从"会后总结"走到了"会中干活"——文档白板现场做出来，等于开完会活也干了一半；但 Team 计划默认就开着，管理员最好先检查一下组织设置，别让它进了不该进的会。

来源：[Just Being Resourceful（11 月 13 日，以 Anthropic 帮助中心为准）](https://justbeingresourceful.com/2026/11/13/anthropic-adds-claude-meetings-to-google-meet/)、[Vanja.io（11 月 13 日）](https://vanja.io/claude-meetings/)

**2. Codex CLI 0.168.0：分屏 side chat 与语音备注；Claude Code 2.1.323 悄悄移除了 subagentStatusLine**

Codex CLI 0.168.0（11 月 13 日前后）：新对话模型选择器、可缩放分屏 side chat、可给音频模型附加录音。Claude Code 2.1.323（11 月 12 日）：实验性 Code Mode（Claude 直接写 JavaScript 批量调工具）之外，一个未作声张的变化是移除了 subagentStatusLine 设置、未给替代项——自定义的子代理成本/上下文/ effort 行直接失效，设置项还在但不再起作用。

为什么值得知道：Codex 在补"边写边聊"的多会话体验，Claude Code 却在悄悄砍自定义项；依赖 subagentStatusLine 做成本展示的人，升级后先检查一下自己的状态行还在不在。

来源：[The Daily Fledgling（11 月 13 日）](https://thedailyfledgling.click/)、[ExplainX（11 月 13 日）](https://explainx.ai/news)

注：11 月 13 日 Claude 认证故障约 2 小时，claude.ai、Claude Code、Console、Cowork 登录失败，API 未受影响，原因未公布（见早报第一部分第 10 条）。

**3. Anthropic 自托管 Claude Managed Agents 进入私有 beta（11 月 12 日）：agent 的控制面可以放在自己家**

Anthropic 开放自托管 Claude Managed Agents 私有 beta：企业可以在自己的云或本地运行 agent 服务器、凭证、沙箱与会话历史，自己决定 Claude 请求发往哪里。此前 Managed Agents 只能跑在 Anthropic 的托管环境里。

为什么值得知道：agent 的控制面从"厂商托管"变成了"可选自托管"——对数据不能出内网的企业，这是 agent 落地真正的门票；但代价是运维责任也一起交过来了，先在小范围跑通再扩大。

来源：[SXF Brief（11 月 13 日）](https://sxf.si/brief/)、[DDS（11 月 13 日）](https://ddsboston.com/blogs/vibe-code-academy/ai-news-for-vibe-coders-daily-2026-11-13)

**4. Gemini Decisions API（11 月 11 日）：一次调用评 1,000 道题，输入 0.10 美元/百万 token**

谷歌推出 Gemini Decisions API：一次调用可对最多 1,000 道是非、选择与打分题评分，接受多模态输入、不逐 token 输出，输入价 0.10 美元/百万 token。定位是"便宜的裁判模型"：给 agent 的候选答案打分、做路由判断，不用再为每道题单独调一次大模型。

为什么值得知道：agent 流程里"判断"与"生成"正在分家——判断交给每百万 token 一毛钱的专用模型，生成再用贵模型；跑批量评估、内容审核、多候选排序的人，先算一下这笔账，0.10 美元的裁判比拿 1.50 美元的 Hydrogen 当裁判便宜 15 倍。

来源：[SXF Brief（11 月 13 日）](https://sxf.si/brief/)

**5. AWS AgentCore 新运行时成 Bedrock 默认：P75 会话启动从 29.7 秒压到 2 秒内**

AWS 的下一代 AgentCore 运行时成为 Bedrock 默认：P75 会话启动从 29.7 秒压到 2 秒以内，8 vCPU/32GB microVM。同日，Kiro 的 MAESTRO 证明 harness 在 1 小时 46 分内解出 6 道 2026 IMO 试题，AWS 称胜过 Codex 与 Claude Code（厂商自称，未经独立验证）。

为什么值得知道：agent  runtimes 的竞争打到了"启动速度"上——29.7 秒到 2 秒，等于 agent 从"泡杯咖啡再回来"变成了"随叫随到"；但 IMO 那 6 道题的胜负是 AWS 自己报的，先当营销看，等第三方复测。

来源：[AI Briefing（11 月 13 日）](https://aibriefing.dev/)

**6. Meta Muse 开放出站电话（11 月 12 日起）：美国付费用户可让 Muse 代打电话给商家**

11 月 12 日起，美国的 Meta Muse 付费订阅用户可以让 agent 代打电话给商家；免费用户仍不可。Muse 出站电话是 Meta 把 agent 从"聊天"推向"代办"的又一步：先打电话问营业时间、订位这类事。

为什么值得知道：agent 代办的边界正在从"线上"扩到"电话"——美联航刚拒绝 agent 代订机票，Meta 转头就让 agent 代打电话；两边拉扯的结果，会决定 agent 到底能替你办多少事。

来源：[ExplainX（11 月 13 日）](https://explainx.ai/news)

**7. ChatGPT Wallet：Dots agent 可代付款，每笔须 Face ID/指纹确认**

OpenAI 推出 ChatGPT Wallet：Dots agent 可用网络支付 token 代付款，不直接看到卡号；每笔购买须 Face ID 或指纹确认；先上美国 Pro 用户，支持 Visa、Mastercard、Amex。

为什么值得知道：agent 代付的卡点一直是"谁担责"——ChatGPT Wallet 的答案是"每笔都由人按指纹确认"，等于把授权动作留给人、把填卡号的脏活交给 agent；这是目前最现实的 agent 支付形态，值得抄。

来源：[ExplainX（11 月 13 日）](https://explainx.ai/news)

## AI 基础设施类

**1. Cerebras 签下微软为第三家超大规模客户，700 MW 已签约，未履行义务 261 亿美元**

Cerebras 11 月 12 日 Q3 财报：核心收入 2.309 亿美元、同比增 70% 创纪录，全年指引上调至 9.4–9.6 亿美元；微软签约成为第三家超大规模客户（继 AWS、Oracle），10 月签约、收入从 2027 年 Q1 起算；已签约数据中心容量 700 MW（2027 年底前交付），未履行义务 261 亿美元。同一场电话会承认：对 OpenAI 的 750 MW 照付不议合同交付落后，原因是土地、电力与厂房而非芯片，预计 2027 年下半年赶上。

为什么值得知道：推理芯片的竞争焦点已经从"谁的卡快"变成"谁能按时交出兆瓦"——Cerebras 的 700 MW 订单与 OpenAI 单子的延迟是同一枚硬币的两面：需求不缺，缺的是电和地。

来源：[Data Center Dynamics（11 月 13 日）](https://www.datacenterdynamics.com/en/news/cerebras-secures-microsoft-as-a-customer/)、[Silicon Sideline（11 月 13 日）](https://siliconsideline.com/blog/cerebras-microsoft-deal-openai-delays)

来源：[Compute World 简报（11 月 13 日，引 Fermi Q3 8-K）](https://compute.world/brief)

**5. SGLang 联盟成立：NVIDIA、AMD、Intel、Google、Meta 等联手做开源推理运行时**
