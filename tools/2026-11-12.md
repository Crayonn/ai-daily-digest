# AI 工具日报 2026-11-12

## AI 工具类

**1. AWS Emulator（11 月 11 日）：200+ AWS 服务的本地模拟器，全部代码由 agent 写成，CC0 开源**

AWS 发布 AWS Emulator：本地模拟 200 多个 AWS 服务、基于 400 多个 API 模型，免费、CC0 公共领域授权，完整提交历史在 GitHub（aws/aws-emulator）。最特别的是它"怎么写出来"的：团队一行代码没写也没审，全部由 Bedrock AgentCore 上的三队 agent 完成——写测试、找问题、修问题，每天清掉数千个 issue。Rust 测试可每个用例内嵌一个隔离实例；每个版本发布各服务的保真度评分；用量遥测默认开启。已知局限也公开写在仓库的 things-that-do-not-work 目录里：不模拟限流、宕机与区域功能差异，不沙箱化运行代码。

为什么值得知道：coding agent 最大的摩擦是"每次验证都要跑真云，又贵又慢"——本地模拟器把这个成本清零；而且它本身就是 agent 协作的标杆案例：保真测试 + 合并门禁，而不是"让 agent 自由发挥"。11 月 11 日当日 GitHub 增速 +1,039 star（见 GitHub 排行第 7 位）。

来源：[About Amazon（11 月 11 日）](https://www.aboutamazon.com/news/aws/how-autonomous-ai-agents-built-aws-emulator?ref=siliconnoon.com)、[GhTrends.dev 11 月 12 日版](https://ghtrends.dev/daily/)

**2. Gemini Decision 1 API（11 月 11 日）：只做判断不写文章，每百万 token 0.10 美元、零输出费**

谷歌推出 Gemini Decision 1 与 Gemini Decisions API：返回预设答案与置信度而非生成文本，单次最多 1000 道是非/选择/量表题，覆盖文本、图像、音频、视频与 PDF；输入价 0.10 美元/百万 token、无输出费，响应 150–250 毫秒，约比 Gemini 3.5 Flash-Lite 便宜五倍。已在 Gemini Notebook（查询路由）、Stitch（原型设计）与搜索（安全检查）内部使用。Artificial Analysis 的 Decision Index 给它 66 分；谷歌对照里它在七项共享基准中的五项领先 Jev 1.14，JevBench 92.2% 对 90.0%。

为什么值得知道：agent 的大量调用是"二选一"不是"写一段话"——路由、分类、审核、打分。把判断层抽成 0.10 美元的专用端点，等于把 agent 每次决策的成本砍到原来的五分之一；对跑 agent 的团队，这比又一个聊天模型更值得马上试。

来源：[SiliconNoon（11 月 11 日）](https://siliconnoon.com/today-in-ai-november-11-2026/)

**3. Qwen4-Max 开启预览（11 月 11 日）：阿里旗舰，主打编程与 agent**

阿里预告 Qwen4 家族，Max 版本通过 Token Plan 与部分产品开启预览；官方公告强调编程与 AI agent 能力。定价、上下文与基准细节尚未公布。

为什么值得知道：Qwen 系列第一次把"Max"旗舰与 agent 场景直接挂钩；对用开源模型搭 agent 的人，这是继 DeepSeek、Kimi 之后又一个值得排队测试的旗舰，关键看它公布的 agent 基准分。

来源：[The Neuron（11 月 11 日）](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-wednesday-november-11-2026/)

**4. ElevenLabs Scribe v3 与 v3 Live（11 月 11 日）：转写词错率比 v2 少 27%，实时版改意错误少 43%**

ElevenLabs 发布 Scribe v3（录音转写）与 v3 Live（实时转写）：公司称 v3 在多语言测试中比 v2 词错率少 27%，实时版比上一代实时模型"改意错误"少 43%。

为什么值得知道：转写模型的竞争已经从"能不能转"打到"错多少"——27% 与 43% 都是"意思会不会被转错"的指标，对会议记录、直播字幕这类"错一个词就变味"的场景，这是最值得看的两个数；但注意这是厂商自测，未经第三方验证。

来源：[The Neuron（11 月 11 日）](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-wednesday-november-11-2026/)

## AI 视频类

**1. MiniMax H3-Image 开源权重：4K 约 10 秒，支持 16 张参考图（11 月 11 日）**

MiniMax 发布 H3-Image 的可下载权重：高速版 4096×4096（约 1600 万像素）约 10 秒出图，约为主流模型同规格用时的五分之一；支持最多 16 张参考图融合、结构化指令，擅长 CAD 风格线图与机械剖面——这正是图像模型常翻车的地方。社区称其为最强开源图像模型，这是社区评价、不是榜单结论。

为什么值得知道：图像模型开源到这个水平，意味着"出图"本身不再是壁垒——4K 十秒、16 图融合、可本地跑，批量做产品图、海报、设计稿的人可以直接拿权重搭自己的管线；但注意"最强"是社区口碑，正式基准还没出。

来源：[SiliconNoon（11 月 11 日）](https://siliconnoon.com/today-in-ai-november-11-2026/)、[The Neuron（11 月 11 日）](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-wednesday-november-11-2026/)

**2. Runway Dev 上 MiniMax H3 Max API：768p 每秒 0.08 美元，5–15 秒带声、数秒出片（11 月 11 日价）**

Runway Dev 上线 fal 版 MiniMax H3 Max API：768p 每秒 0.08 美元（480p 更低），文生或图生视频 5–15 秒、带原生声音，数秒返回成片；支持首帧 + 可选尾帧、提示词最长 6000 字符。与 H3 本体对比：H3 Max 求快（数秒），H3 本体求全（支持参考图/视频/音频、最高 2K，但耗时数分钟）。
