# AI 工具日报 2026-10-19

## 一、AI 工具类

**1. Claude Code 本周 4 连发：idle 自动压缩上线，@大文件不再爆上下文**

aicoding-guide 周报：v2.1.299–2.1.302 新增 idle compaction——200K+ token 的会话闲置约 54 分钟后自动压缩，避免 prompt cache 过期后重算全量。`CLAUDE_CODE_DISABLE_FILE_MENTIONS` 让 `@` 大文件时只传路径不传内容，Claude 自己按需读。

为什么值得知道：跑长任务的人能省一笔 cache 钱；`@` 大文件爆上下文的老问题有官方解了。

来源：[aicoding-guide](https://aicoding-guide.com/en/posts/weekly-2026-10-18/)

**2. TurboAI 更新：Claude Code v2.1.303、Amp 每日构建、OpenCode 2 进展**

Alex Sorokoletov 的发布追踪：Claude Code v2.1.303（fork subagents 默认开）、Amp 10-18 当天 8 个构建、OpenCode v1.19.2 与 2.x 分线维护、Codex CLI v0.163.0（Daybreak 重新默认启用）。

为什么值得知道：coding agent 现在是"按天发版"的节奏，盯 TurboAI 这一个站就行，不用每个 repo 翻 changelog。

来源：[TurboAI](https://www.turboai.dev/)

**3. Gemini 4 Argon：后台任务模式，能跨 40+ 应用自主干活**

Google AI Pro / Ultra 专属（10 月 13 日上线）：Tasks 模式让 Gemini 在后台跨 Google 系和第三方应用自主执行任务，人不用守着电脑。

为什么值得知道：这是 Google 把"agent"做进订阅制的标志动作；和 Claude Code 那种终端 agent 是两条路线。

来源：[wasifahmed.dev](https://wasifahmed.dev/gemini-4-argon-gemini-app-update/)

## 二、AI 视频类

**1. 横评：Veo 3.1 vs Kling 3.0 vs Runway Gen-4.5，10 月该怎么选**

trendintech 盲测横评结论：Veo 3.1 拿下 LMArena 图生视频榜 1397 Elo，短而精+原生对白选它（$0.40/秒）；Kling 3.0 拿下 Artificial Analysis 文生视频榜 1251，片长接近 Veo 两倍+有免费日额度，预算有限默认选它（$10/月起）；Runway Gen-4.5 配 Aleph 2.0 不拼生成拼剪辑，是唯一为"修已有素材"设计的。量大还有隐藏选项：Wan 3.0 不到 $0.10/秒。

为什么值得知道：一张表把"画质/片长/价格/场景"四个维度一次讲清，发视频前先看这篇能省试错钱。

来源：[trendintech](https://trendintech.com/veo-3-1-vs-kling-3-0-vs-runway-gen-4-5-2026/)

**2. Protoface API 一次接入 40+ 生成模型**
