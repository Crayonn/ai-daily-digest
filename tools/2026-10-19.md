# AI 工具日报 2026-10-19

## 一、AI 工具类

**1. Claude Code 本周 4 连发：idle 自动压缩上线，@大文件不再爆上下文**

aicoding-guide 周报（10-18）：v2.1.299–v2.1.303 四连发。核心是 idle compaction——200K+ token 的会话闲置约 54 分钟后自动压缩，赶在 1 小时 prompt cache 过期前做完，下次提问不用重算全量，直接省 cache 钱。`idleCompaction: false` 可关。

另外两个实用更新：`CLAUDE_CODE_DISABLE_FILE_MENTIONS`——`@` 大文件时只传路径不传内容，Claude 按需自己读，专治"@个日志文件上下文就炸"；v2.1.303 把 fork subagents 默认打开。

注意：compaction 会把对话压成摘要，`CLAUDE.md` 会重读但文件内容会被折叠——靠上下文细节干活的工作流建议关掉。

为什么值得知道：跑长任务的人今天就可以去开 idle compaction，cache 账单肉眼可见地降。

来源：[aicoding-guide](https://aicoding-guide.com/en/posts/weekly-2026-10-18/)、[TurboAI](https://www.turboai.dev/)
